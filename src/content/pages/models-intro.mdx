評測分數是模型能力在某一天、某一種設定下的快照，不是絕對排名。本站的模型頁會把每個分數連同測試日期、設定與出處一起列出。比較之前，建議先確認五件事：

1. **測的是什麼？** 綜合指數把多項測驗合併成一個分數，例如 Artificial Analysis 智慧指數 v4.3.2 納入 10 項評測，分成 Agent、程式、科學推理與一般能力四類加權，而且以英文文字題為主<Cite k="aa-method" />。單項評測只測一種能力，例如研究所程度的科學問答，或修復真實程式錯誤。分數高的模型不一定在你的任務、你的語言上表現最好。
2. **誰測的？** 實驗室自評通常使用對自己最有利的設定；第三方機構與排行榜用一致的方法重測，比較適合跨模型比較。本站分別標示「實驗室自評」「第三方」與「排行榜」。
3. **何時測的？** 模型每隔幾個月就推出新版本，評測本身也會改版。兩個分數的日期相差超過 90 天時，頁面會加上提醒。舊評測若已接近滿分，或題目可能混進訓練資料，參考價值也會下降。
4. **標準答案還是人類偏好？** 多數評測比對標準答案；競技場類排行榜則是讓使用者同時看兩個匿名模型的回答，再投票選出較好的一個<Cite k="arena-how" />。這反映的是使用者偏好，回答的長度與排版風格也可能影響投票，因此競技場另外提供控制風格因素後的排名<Cite k="arena-style" />。
5. **實際要花多少錢？** API 價格以每百萬 Token 計，輸入與輸出分開計價。推理模型在回答前會先產生大量「思考」Token，這些 Token 通常也按輸出價格計費<Cite k="openai-reasoning" />，所以完成同一件事實際用掉的 Token 可能遠多於最後看到的答案；只看每百萬 Token 的牌價，容易低估實際成本。

<Callout type="tip" title="模型星系的三個座標">
綜合能力、成本指數與開放程度，是本站為了幫助理解而整理的定位，不是排行榜。成本指數以輸入與輸出 3 比 1 混合的牌價取對數換算；開放程度從完全封閉、開放權重到連訓練資料都公開分成數級。每個系列頁都會寫明座標的依據與日期。
</Callout>
