## 公司概況

Weaviate 由 Bob van Luijt 與 Etienne Dilocker 在 2019 年創立，總部位於阿姆斯特丹，並在美國與澳洲設有據點<Cite k="wv-b" />。它的開源向量資料庫同時儲存嵌入向量與原始資料物件，支援向量與關鍵字的混合搜尋，常被用來建構 <LearnLink id="rag-and-vector-search">RAG 應用</LearnLink>；官網稱下載次數逾 1,500 萬、員工逾 90 人<Cite k="wv-about" />。2023 年 4 月由 Index Ventures 領投募得 5,000 萬美元，同時推出託管的 Weaviate Cloud<Cite k="wv-b" />，與 <CompanyChip id="pinecone">Pinecone</CompanyChip>、<CompanyChip id="qdrant">Qdrant</CompanyChip>、<CompanyChip id="zilliz">Zilliz</CompanyChip> 競爭。

## 近期動態

Weaviate 正把定位從「向量資料庫」延伸到 Agent 基礎設施：2026 年 4 月推出託管記憶服務 Engram（推出時官方表示仍在邁向正式版），讓 Agent 跨工作階段記住使用者偏好並在多個 Agent 間共用記憶<Cite k="wv-engram" />；8 月的 1.39 版讓 Boost API 與 MMR 多樣性篩選正式上線，並預覽 4 位元旋轉量化以壓低記憶體用量<Cite k="wv-139" />。
