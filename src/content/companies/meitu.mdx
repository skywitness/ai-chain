## 公司概況

美圖以美圖秀秀等修圖 App 起家，近年把重心轉向「AI 生產力工具」，讓電商賣家、內容創作者用 Agent 完成商品圖、海報與口播影片。它採取「自研加調度」的模型策略：自研的 MiracleVision 只專攻人像相關的關鍵操作，其他需求由 Agent 挑選最合適的第三方模型<Cite k="meitu-h126" />。2025 年持續經營業務營收 38.6 億元人民幣、年增 28.8%，並引進 <CompanyChip id="alibaba">阿里巴巴</CompanyChip> 認購 2.5 億美元可轉債<Cite k="meitu-fy25" />。

## 近期動態

2026 年上半年營收 22.1 億元人民幣、年增 22.1%，付費訂閱用戶逾 1,844 萬；生產力類 App 月活躍用戶達 3,300 萬、創下新高，AI 生產力應用的年化經常性收入（ARR）約 6.2 億元人民幣。6 月起，美圖設計室由單一 Agent 升級為多個 Agent 分工的 Agent Teams<Cite k="meitu-h126" />。毛利率則由 75.3% 降至 71.5%，公司解釋是早期 AI 生產力 App 成長較快、每單位營收的模型 API 成本較高，加上高毛利的廣告占比下降<Cite k="meitu-h126" />。
