## 系列概覽

FLUX 是德國 <CompanyChip id="black-forest-labs">Black Forest Labs</CompanyChip>（BFL，黑森林實驗室）的<Term id="generative-ai">生成式 AI</Term>圖像模型系列。BFL 自稱採「開放核心」路線：一方面推出可下載的<Term id="open-weights">開放權重</Term>模型讓社群研究與改作，一方面以 API 銷售品質更高的商用版本，客戶包括 Adobe 與 Meta 等<Cite k="bfl-flux2" />。

截至 2026-10-06，系列有兩代並行。**FLUX.2**（2025-11 起）是目前最完整的圖像產品線，從閉源的 [max]、[pro]、[flex] 到開放權重的 [dev] 與 [klein] 都有；**FLUX 3**（2026-07-23 發表）則是一個同時學習圖像、影片與音訊的<Term id="multimodal">多模態</Term>基礎模型，BFL 依序推出 FLUX 3 Video、FLUX 3 Action，以及 2026-10-01 上線的 FLUX 3 Image<Cite k="bfl-rn" />。

## 特性分析

**架構：視覺語言模型加上流匹配。** FLUX 系列採潛空間流匹配（flow matching），屬於<Term id="diffusion-model">擴散模型</Term>的延伸。FLUX.2 把 <ModelChip id="mistral">Mistral</ModelChip> 的 240 億參數視覺語言模型（官方稱 Mistral-3 24B）接上整流流 Transformer：前者提供世界知識與語意理解，後者負責空間關係與材質，並重新訓練了潛空間編碼器<Cite k="bfl-flux2" />。FLUX 3 則以自家的 Self-Flow 方法，在同一個架構中同時訓練生成與理解<Cite k="bfl-flux3" />。

**編輯能力是主軸。** FLUX.2 可同時參考最多 10 張圖，維持角色、商品或風格一致，輸出最高 4MP，並能以 HEX 色碼指定品牌色<Cite k="bfl-flux2" />。FLUX 3 Image 更進一步，允許在提示詞後面加上一串邊界框，指定標題、人物或格子的位置，再逐框改色、移動或刪除，其他部分維持不變<Cite k="bfl-rn" />。

**按張計價、價格分層。** FLUX 不以 token 計價：FLUX 3 Image 1K 每張 0.048 美元、4K 每張 0.607 美元；FLUX.2 [pro] 首百萬像素 0.03 美元，[klein] 4B 只要 0.014 美元；FLUX 3 Video 則按秒收費，FHD 每秒 0.29 美元<Cite k="bfl-pricing" />。

**跨進物理 AI。** FLUX 3 Action 是 70 億參數的開放權重<Term id="world-model">世界動作模型</Term>，輸入相機畫面、機器人狀態與文字指令，同時預測下一段動作與畫面；BFL 稱它在 RoboLab-120 排行榜創下新的最高成功率（38.3%，先前最佳的開放模型 Cosmos 3 Nano 為 36.8%），參數量卻不到後者的一半<Cite k="bfl-flux3-action" />。這讓圖像公司直接接上<Term id="physical-ai">實體 AI</Term>與機器人的需求。

## 適合與不適合的用途

適合：

- **大量出圖的商業應用**：電商、行銷素材、廣告變體，單張成本遠低於 GPT Image 等閉源模型。
- **多參考圖編輯**：同一角色、同一商品在不同場景間保持一致。
- **本機或自建部署**：FLUX.2 [klein] 4B 為 Apache 2.0，官方稱約 13GB 顯示記憶體即可執行<Cite k="bfl-rn" />。
- **精確排版的設計稿**：FLUX 3 Image 的邊界框可控制每個元素的位置。

不適合：

- **追求人類偏好評比第一名**：AA 文生圖榜前幾名由 GPT Image、Grok Imagine、MAI-Image 等占據，FLUX.2 最高排第 22 名<Cite k="aa-t2i" />。
- **想免費商用中高階開放權重**：FLUX.2 [dev] 與 [klein] 9B 為非商用授權，需另購方案。
- **需要長期固定的 API 版本**：舊端點汰換快，FLUX Pro 1.0 與微調 API 已在 2025-10-31 停用。
