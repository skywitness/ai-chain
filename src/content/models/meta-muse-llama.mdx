## 系列概覽

<CompanyChip id="meta">Meta</CompanyChip> 的語言模型可以分成兩個時代。2023 到 2025 年是 Llama：從 Llama 2 起開放權重並允許多數商業用途<Cite k="wiki-llama" />，最後一代是 2025-04-05 發布、首度採用<Term id="moe">混合專家（MoE）</Term>架構的 Llama 4 Scout 與 Maverick<Cite k="meta-llama4-blog" />。據 Bloomberg 報導，祖克柏不滿 Llama 4 的表現；Meta 隨後以 143 億美元取得 <CompanyChip id="scale-ai">Scale AI</CompanyChip> 49% 無表決權股份、延攬其執行長 Alexandr Wang 擔任首席 AI 長，並在 2025 年 6 月成立 Meta 超級智慧實驗室（MSL）<Cite k="wiki-msl" />。

MSL 的第一個成果是 2026-04-08 發表的 Muse Spark。Meta 說團隊花了九個月從頭重建 AI 技術堆疊，這個模型「刻意做得小而快」，更大的模型仍在開發中<Cite k="meta-muse-spark-launch" />。Muse Spark 不公開權重，取代 Llama 成為 Meta AI 助理的核心；7 月起 Meta 以約每月一版的節奏推出 1.1、1.2 與 1.3，並在 8 月釋出 Apache 2.0 授權的小型開放模型 Muse Glimmer<Cite k="wiki-muse-spark" />。

2026 年 10 月起，產品線一口氣拉開。10-12 推出在吉瓦級 Prometheus 資料中心訓練的 Muse Wonder 與 Muse Wonder Full，Meta 稱為「擴展階梯」的下一步<Cite k="meta-muse-wonder-blog" />；10-15 釋出開放權重的 Muse Spark Open<Cite k="meta-muse-spark-open-blog" />；11-09 推出最小的 Muse Ember，也是第一個用 Muse Wonder Full 訓練的模型。Meta 現在的分工是：Wonder 處理最難的問題，Spark 負責程式與 Agent 工作流程，Ember 承擔大量重複的任務<Cite k="meta-muse-ember-blog" />。

## 特性分析

**價格分成三層。** Meta Model API 標準價（每百萬 tokens，輸入／輸出）：Muse Wonder 4／20 美元、Muse Spark 1.3 1.25／4.25 美元、Muse Ember 0.10／0.50 美元（提示超過 20 萬 tokens 時為 0.30／1.50 美元），上下文都是 100 萬 tokens<Cite k="meta-model-api" />。能力最強的 Muse Wonder Full 沒有按量計價，只在 Muse Code 每月 50 或 200 美元的訂閱方案中提供<Cite k="meta-muse-wonder-page" />。Spark 1.2 與 1.3 另有 contributor 方案，每百萬 tokens 只要 0.10／0.20 美元，但資料會被用來改進 Meta 的產品；標準方案則不會<Cite k="meta-model-api" />。

**單價便宜，不等於總花費便宜。** Artificial Analysis（AA）跑完 v5 綜合智慧指數時，Muse Spark 1.3（Max）共輸出約 1.23 億 tokens<Cite k="aa-muse-spark-1-3" />，Muse Wonder（Max）約 1.13 億 tokens，都高於同價位模型的中位數<Cite k="aa-muse-wonder" />。反過來，AA 算出 Muse Ember 以 Claude Haiku 5.5（Max）約三分之一的每任務成本，拿到同樣的 36 分<Cite k="aa-muse-ember-article" />。

**推理、多模態與 Agent。** Muse 各型號都是<Term id="reasoning-model">推理模型</Term>，可調整推理強度；API 同時相容 OpenAI 與 Anthropic 的請求格式<Cite k="meta-dev-blog" />。Muse Wonder 的輸入可為文字、影像、影片與音訊<Cite k="meta-muse-wonder-card" />，並以 Active Memory（跨對話記住使用者脈絡）與 Active Focus（遇到阻礙時持續嘗試、重要動作前先確認）為賣點<Cite k="meta-muse-wonder-blog" />。

**開放權重回來了，但不是寬鬆授權。** Muse Spark Open 是 MoE 模型，總參數 8,160 億、每個 token 啟用 420 億（256 個專家中選 8 個），上下文 100 萬 tokens。授權要求在產品中標示「Built with Muse Spark Open」；以 API 提供模型服務、且任一連續 12 個月營收（含關係企業）超過 2,000 萬美元的業者，須先通知 Meta 並另簽協議<Cite k="hf-muse-spark-open" />。自行部署的門檻也高：官方建議 NVFP4 版本至少 700GB 顯示記憶體、BF16 約 2TB；Meta 另表示可在兩台 Apple M5 Ultra Mac Studio 上以 MLX 執行<Cite k="meta-muse-spark-open-blog" />。小型的 Muse Glimmer 則是從 Muse Spark <Term id="distillation">蒸餾</Term>而來的<Term id="dense-model">稠密模型</Term>，約 296 億參數、Apache 2.0 授權，量化後可放進 24GB 顯示卡，並附<Term id="speculative-decoding">推測解碼</Term>草稿模型<Cite k="hf-muse-glimmer" />。

## 適合與不適合的用途

適合：

- **前沿等級的 Agent 與程式工作**：Muse Wonder 可經 Meta Model API、Muse Code、OpenRouter 與 Google Cloud 使用<Cite k="meta-muse-wonder-page" />。
- **大量重複的子任務**：工具呼叫、程式子任務、路由與文件擷取交給 Muse Ember，規劃與協調交給 Wonder 或 Spark<Cite k="meta-muse-ember-blog" />。
- **超長文件與程式庫**：主力型號的<Term id="context-window">上下文視窗</Term>都是 100 萬 tokens。
- **自行部署**：Muse Spark Open 可從 Hugging Face、Amazon SageMaker、Google Cloud Model Garden 與 Microsoft Foundry 取得權重<Cite k="meta-muse-spark-open-blog" />；資料完全不能離開公司的小團隊，可用 Muse Glimmer 離線執行。
- **Meta 生態系內的體驗**：Muse Spark 驅動 Meta AI，2026 年 5 月起陸續進入 WhatsApp、Instagram、Facebook、Messenger、Threads，以及 Ray-Ban Meta、Oakley Meta 眼鏡<Cite k="meta-muse-spark-launch" />。

不適合：

- **需要旗艦權重或可稽核性的研究**：Wonder 系列閉源，參數量與架構都未公開。
- **想透過 API 使用最強版本的團隊**：Wonder Full 只在 Muse Code 訂閱中提供。
- **規模較大的模型 API 業者**：Muse Spark Open 有營收門檻與標示義務，不能像 Apache 2.0 模型那樣無條件商用。
- **繼續押注 Llama 的團隊**：Llama 4 之後沒有新的 Llama，預告中的 Llama 4 Behemoth 也始終未釋出<Cite k="wiki-llama" />。
