## 系列概覽

GLM 是<CompanyChip id="zhipu-ai">智譜（Zhipu AI，國際品牌 Z.ai）</CompanyChip>的大型語言模型系列。2025 年中以後，智譜大約每兩個月推出一個新旗艦，而且多半同步在 Hugging Face 公開權重：GLM-4.5（2025-07）、GLM-4.6（2025-09）、GLM-4.7（2025-12）、GLM-5（2026-02）、GLM-5.1（2026-04）、GLM-5.2（2026-06），以及截至 2026-11-13 仍是最新的 GLM-5.3（2026-08-18）與 GLM-5.3-Flash（2026-08-26）<Cite k="zai-release" />。GLM-5.3 之後近三個月沒有新的旗艦，Hugging Face 上也沒有新的權重<Cite k="hf-zai-org" />；10 月的新品是只透過 API 提供的法律領域版 GLM-5.3-FlashX-Legal<Cite k="zai-glm53flash-doc" />。

GLM-5.3 沿用 GLM-5.2 的基礎模型，進步全部來自後訓練。它只接受文字輸入，<Term id="context-window">上下文視窗</Term>為 100 萬 tokens、最大輸出 12.8 萬 tokens，而且是一律開啟推理的<Term id="reasoning-model">推理模型</Term>，只能在 low、high、max 三段強度之間切換<Cite k="zai-glm53-doc" />。在 Artificial Analysis（AA）2026-10-27 改版的綜合智慧指數 v5.0.1 中，GLM-5.3（max）得 32 分，在 AA 評測的<Term id="open-weights">開放權重</Term>模型裡排第三，僅次於 <ModelChip id="moonshot-kimi" /> 的 Kimi K3.1 Pro（46 分）與 <ModelChip id="deepseek" /> 的 DeepSeek V4.1 Flash 1017（33 分）<Cite k="aa-leaderboard-v5" />。

## 特性分析

**以程式與長程 Agent 為主軸。** GLM-5 把參數從 GLM-4.5 的 3,550 億（<Term id="active-parameters">啟用參數</Term> 320 億）擴大到 7,440 億（啟用 400 億），並導入 DeepSeek 的<Term id="sparse-attention">稀疏注意力</Term>來降低長上下文成本<Cite k="zai-glm5-doc" />。之後 GLM-5.1 主打單次自主工作 8 小時，GLM-5.2 把可用上下文推到 100 萬 tokens<Cite k="zai-release" />。GLM-5.3 官方稱在自家 Z.ai Code Bench 比 GLM-5.2 進步 50%，較難的 Terminal-Bench 3.0 則從 4.6% 提升到 28.3%<Cite k="zai-glm53-doc" />。

**資安能力是兩面刃。** GLM-5.3 在漏洞挖掘評測 CyberGym 得 84.5%；智譜也說與多個資安團隊合作，在 269 個專案中確認 2,436 個漏洞，其中 1,097 個屬中高風險<Cite k="zai-glm53-doc" />。防守方多了工具，濫用風險也同步升高。

**旗艦與 Flash 兩條線。** GLM-5.3-Flash 是 GLM-5 系列第一個原生<Term id="multimodal">多模態</Term>模型，採全新訓練的基礎模型，總參數 3,200 億、每個 token 啟用 180 億，混合線性與稀疏注意力，注意力運算與 <Term id="kv-cache">KV cache</Term> 分別比 GLM-5.3 少 3.01 倍與 4.44 倍，可輸入圖片、影片與檔案<Cite k="zai-glm53flash-doc" />。API 價格為每百萬 tokens 輸入 0.15、輸出 0.50 美元，約是 GLM-5.3（1.4／4.4 美元）的九分之一<Cite k="zai-pricing" />。

**往垂直領域延伸。** 2026 年 10 月，價目表加入 GLM-5.3-FlashX-Legal，官方文件把它放在 GLM-5.3-Flash／FlashX 之下：先以大量法律資料做中期訓練與後訓練，再在數萬個模擬真實法律工作的環境中做強化學習，用於法律研究、合約審閱與文件起草；API 參數設定與 Flash 相同，支援 100 萬 tokens 上下文。官方稱它在法律 Agent 評測 Harvey LAB 的全項通過率為 19.2%，比基礎模型高 12.5 個百分點，這是自家公布的數字<Cite k="zai-glm53flash-doc" />。官方沒有公布上線日期，價目頁的網頁存檔顯示它在 2026-10-17 到 10-24 之間出現，價格與 FlashX 相同（每百萬 tokens 輸入 0.37、輸出 1.25 美元）<Cite k="zai-pricing" /><Cite k="zai-pricing-archive" />。

**授權開始分歧。** GLM-5 到 GLM-5.2，以及 GLM-5.3-Flash，都採 MIT 授權；GLM-5.3 改用自訂授權，條款大致寬鬆，但規定經營「模型即服務」、且集團年營收超過 100 億美元的業者，商用前須通過 Z.ai 的安全審查<Cite k="hf-glm53-license" />。

## 適合與不適合的用途

適合：

- **程式 Agent 與終端機自動化**：官方提供 OpenAI 與 Anthropic 相容的 API 端點，可直接接入 Claude Code 等工具<Cite k="zai-glm53-doc" />。
- **自建部署**：模型卡列出 SGLang、vLLM、Transformers 等推論框架，也支援華為昇騰 NPU<Cite k="hf-glm53" />，適合資料不能離開機房的企業。
- **大量、在意成本的多模態工作**：GLM-5.3-Flash 能看圖片與影片，價格又低。
- **法律文件工作流程**：GLM-5.3-FlashX-Legal 搭配官方建議的法規、判決查詢與 Word 文件編修 MCP 服務，可做合約審閱與文件初稿<Cite k="zai-glm53flash-doc" />；它只透過 API 提供，2026-11-13 查詢時 Hugging Face 上沒有它的權重<Cite k="hf-zai-org" />。

不適合：

- **需要圖片或影片輸入，卻想用旗艦版**：GLM-5.3 只接受文字。
- **對延遲敏感的即時互動**：GLM-5.3 無法關閉推理，回答前一定先「想」一段。AA 以 v5.0.1 指數測試（2026-11-13 讀取）時，GLM-5.3（max）輸出速度約每秒 72 tokens，平均每題要 27.7 分鐘，同級開放權重模型的中位數為 14.6 分鐘；跑完指數產生 1.35 億 tokens，也多於同級中位數 1.06 億，等待時間與費用都會跟著拉長<Cite k="aa-glm53-v5" />。
- **大型雲端模型服務商**：集團年營收超過 100 億美元、又經營模型 API 服務的業者，商用前須先通過授權審查<Cite k="hf-glm53-license" />。
