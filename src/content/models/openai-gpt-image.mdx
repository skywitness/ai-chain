summary: "OpenAI 的圖像生成與編輯模型系列，接替 DALL·E，內建於 ChatGPT 並透過 API 提供。首代於 2025 年 3 月以「GPT-4o 圖像生成」推出，之後依序發布 GPT Image 1.5、2、2.5 與 2.6。最新的 GPT Image 2.6（2026-11-04）延續雙版本設計：重視細節與編輯的 Sunburst、主打快速迭代的 Flare，並新增 SVG 向量圖與動態 GIF 輸出；在 Artificial Analysis 文生圖競技場包辦前五名。強項是指令遵循與圖中文字，代價是單張成本偏高。"
strengths:
  - "AA 文生圖競技場（AA-Image-T2I v2.1，2026-11-13）前五名都是 GPT Image：2.6 Sunburst 1261、2.5 Sunburst 1229、2.6 Flare 1226、2.5 Flare 1210、GPT Image 2 1191"
  - "GPT Image 2.6 新增可調整出圖前規劃程度的 complexity 參數、標註式修圖，以及 SVG 向量圖與 2 到 16 格的動態 GIF 輸出"
  - "原生多模態：可同時輸入文字與圖片，並可透過 Responses API 在對話中多輪修圖"
  - "GPT Image 2 起支援彈性尺寸，最長邊 3,840 像素（約 4K），並可輸出透明背景"
  - "與 ChatGPT 及 GPT 文字模型直接整合，容易串成 Agent 或設計工作流程"
weaknesses:
  - "單張成本高：AA 估算 GPT Image 2.6 Sunburst（max）每千張約 211 美元，Nano Banana 2.1 約 34 美元"
  - "GPT Image 2.6 目前不支援 Batch，無法享有 2.5 與 2 的 Batch 半價"
  - "官方文件仍列出限制：複雜提示可能要 2 分鐘、文字精確排版與角色一致性仍可能出錯"
  - "版本汰換快：gpt-image-2 推出不到 7 個月就公告棄用（2027-02-10 下架），整合到產品中需預留遷移時間"
  - "閉源、只能經 API 使用，無法自行部署或微調；使用 API 前可能需先完成組織驗證"
bestFor:
  - "含大量文字的海報、資訊圖表與簡報插圖"
  - "既有圖片的精細修改與商品圖編輯"
  - "需要與 GPT 對話流程整合的多輪設計工作"
  - "圖示、標誌草稿等需要可編輯向量檔（SVG）或簡短動態 GIF 的素材"

## 系列概覽

GPT Image 是 <CompanyChip id="openai">OpenAI</CompanyChip> 的<Term id="generative-ai">生成式 AI</Term>圖像模型系列，接替 DALL·E，內建於 ChatGPT（ChatGPT Images），也透過 API 提供。首代在 2025-03-25 以「GPT-4o 圖像生成」在 ChatGPT 推出，OpenAI 表示第一週就有超過 1.3 億名使用者產生 7 億多張圖；2025-04-23 以 gpt-image-1 的名稱開放 API<Cite k="wiki-gpt-image" />。

和 DALL·E 2、3 使用的<Term id="diffusion-model">擴散模型</Term>不同，GPT Image 採自迴歸方式生成，屬於原生<Term id="multimodal">多模態</Term>的語言模型架構，能同時理解文字與圖片<Cite k="wiki-gpt-image" />。2026-11-04，OpenAI 發布 GPT Image 2.6，延續 2.5 的雙版本設計：Sunburst 用於細節豐富的視覺工作，Flare 用於快速迭代<Cite k="oai-changelog" />。截至 2026-11-13，官方指南建議新的整合直接採用 2.6；2026-09 推出的 2.5 仍可使用，gpt-image-2 則已公告棄用<Cite k="oai-image-guide" /><Cite k="oai-deprecations" />。

## 特性分析

**文字與圖片都能當輸入。** 模型接收文字與圖片、輸出圖片；透過 Responses API，還能在對話中多輪修改同一張圖，或讓 GPT 文字模型呼叫圖像生成工具（官方範例以 2.5 為例，2.6 的新功能則列為經 Image API 提供）<Cite k="oai-image-guide" />。

**2.6 的新功能。** 2.6 的兩個版本都能用 complexity 參數（low、medium、high，預設 high）調整出圖前的規劃程度：較低適合換背景、改招牌這類局部修改，較高有助於密集文字、複雜版面與物件之間的關係，但會增加延遲，也可能帶來不想要的改動；調整 complexity 不另收費。另外新增三種用法：用標註圖層指出要改的位置（標註式修圖，2.5 也支援）、輸出可編輯路徑與顏色的 SVG 向量圖，以及 2 到 16 格的動態 GIF<Cite k="oai-image-guide" />。SVG 是先生成一張參考圖再轉成向量，費用包含圖像模型與負責撰寫 SVG 的模型兩部分<Cite k="oai-image-guide" />。據 Wikipedia 整理的媒體報導，ChatGPT 也同步加入以文字或上傳照片製作動態 GIF 的功能<Cite k="wiki-gpt-image" />。

**尺寸與畫質更彈性。** GPT Image 2 起支援自訂尺寸，寬高須為 16 像素的倍數、最長邊 3,840 像素、總像素上限約 829 萬（4K），也可輸出 PNG、WebP 透明背景。2.5 與 2.6 的 Sunburst、Flare 都提供 low、medium、high、xhigh、max 五個畫質等級，官方文件並註明 2.5 版超過 2560×1440 的解析度仍屬實驗性功能<Cite k="oai-image-guide" />。Wikipedia 整理指出，2.5 版把生成延遲縮短約一半，並在 ChatGPT 加入把手繪草圖轉成圖片的 Sketch 功能<Cite k="wiki-gpt-image" />。

**以 <Term id="token">token</Term> 計價。** 2.6、2.5 與 2 的官方價格相同，每百萬 tokens：文字輸入 5 美元、圖片輸入 8 美元、圖片輸出 30 美元；2.5 與 2 的 Batch 半價，2.6 目前不在 Batch 價目表上<Cite k="oai-pricing" />。實際每張成本取決於尺寸與畫質：以 GPT Image 2 的 1024×1024 為例，low 約 0.006 美元、medium 約 0.053 美元、high 約 0.211 美元<Cite k="oai-image-guide" />。官方也提醒，單價相同不代表每張成本相同，因為不同版本與畫質消耗的 token 數不一樣。

**已知限制。** 官方文件列出：複雜提示可能要 2 分鐘才完成；文字的精確位置、跨多張圖的角色或品牌一致性、需要精準排版的構圖，仍可能出錯<Cite k="oai-image-guide" />。使用 API 前也可能需要先完成組織驗證。

## 適合與不適合的用途

適合：

- **含大量文字的圖像**：海報、資訊圖表、簡報插圖、菜單等需要正確字樣的設計。
- **既有圖片的修改**：換背景、換場景、局部修圖；2.6 可用標註圖層指出修改位置。
- **向量圖示與簡短動畫**：2.6 能直接輸出 SVG 與動態 GIF，適合圖示、標誌草稿與社群貼圖。
- **與文字工作流程整合**：在 ChatGPT 或 Agent 流程中邊討論邊產生、修改圖片。
- **數量不多但要求品質的素材**：在人類偏好評比中名列前茅。

不適合：

- **大量、低單價的生成**：AA 估算 GPT Image 2.6 Sunburst（max）每千張約 211 美元，<ModelChip id="google-nano-banana" /> 的 Nano Banana 2.1 約 34 美元、Meta 的 Muse Image 約 10 美元<Cite k="aa-t2i" />。
- **需要自行部署或微調**：GPT Image 只能經 API 使用，可考慮有開放權重版本的 <ModelChip id="bfl-flux" />。
- **影片生成**：OpenAI 的 Sora 2 與 Videos API 已於 2026-09-24 關閉，官方沒有指定替代模型<Cite k="oai-deprecations" />；2.6 的動態 GIF 最多 16 格，只適合簡短循環動畫。
- **精準的版面控制**：官方承認構圖與元素定位仍不夠穩定。

資料讀取於 2026-11-13<Cite k="aa-t2i" />。解讀時有幾點要注意：

- **v2.1 與 v2.0 的分數不能直接比較**：本站 2026-10-06 讀取時，AA 用的還是 v2.0 榜，當時 2.5 Sunburst 為 1197、GPT Image 2 為 1172<Cite k="aa-t2i-v20" />。之後 AA 改為 v2.1，換用更嚴謹的統計方法（信賴區間納入其他模型評分的不確定性，排名區間改由模擬整個榜單得出），並移除 AA 不再維護或票數太少的模型<Cite k="aa-image-method" />。同一模型在 v2.1 的分數較高，主要是計分方法改變，不代表模型本身變好。另外，AA 的語言模型綜合智慧指數在 2026-10-27 改版為 v5，那是另一套評測，與本頁的圖像 Elo 無關。
- **2.6 Sunburst 明顯領先**：比第 2 名高 32 分，兩者的信賴區間沒有重疊；2.6 Flare 與 2.5 Sunburst 只差 3 分，AA 把兩者的排名區間都標為 2 到 3，可視為並列。
- **新版本樣本較少**：2.6 兩個版本上榜不到兩週，比較次數約 5,300 與 7,200 次，少於 2.5 的約 13,000 次，分數仍可能變動。
- **偏好不等於正確**：Elo 反映評審覺得哪張圖較好、較符合提示，不直接衡量文字拼寫正確率、多輪編輯的一致性，或 SVG、GIF 這類新輸出；而且 AA 測的是 max 或 high 畫質，使用預設 auto 時的畫質與成本都可能不同。
- **性價比要另外算**：前五名每千張約 211 美元，第 6 名的 Nano Banana 2.1 只要約 34 美元。大量生成的應用，第二梯隊的成本效益可能更好。
