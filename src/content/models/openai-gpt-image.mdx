## 系列概覽

GPT Image 是 <CompanyChip id="openai">OpenAI</CompanyChip> 的<Term id="generative-ai">生成式 AI</Term>圖像模型系列，接替 DALL·E，內建於 ChatGPT（ChatGPT Images），也透過 API 提供。首代在 2025-03-25 以「GPT-4o 圖像生成」在 ChatGPT 推出，OpenAI 表示第一週就有超過 1.3 億名使用者產生 7 億多張圖；2025-04-23 以 gpt-image-1 的名稱開放 API<Cite k="wiki-gpt-image" />。

和 DALL·E 2、3 使用的<Term id="diffusion-model">擴散模型</Term>不同，GPT Image 採自迴歸方式生成，屬於原生<Term id="multimodal">多模態</Term>的語言模型架構，能同時理解文字與圖片<Cite k="wiki-gpt-image" />。截至 2026-10-06，API 主推 2026-09-08 發布的 GPT Image 2.5，分成兩個版本：重視編輯精準度的 Sunburst，以及主打速度、適合日常生成的 Flare<Cite k="oai-image-guide" />。

## 特性分析

**文字與圖片都能當輸入。** 模型接收文字與圖片、輸出圖片；透過 Responses API，還能在對話中多輪修改同一張圖，或讓 GPT 文字模型呼叫圖像生成工具<Cite k="oai-image-guide" />。

**尺寸與畫質更彈性。** GPT Image 2 起支援自訂尺寸，寬高須為 16 像素的倍數、最長邊 3,840 像素、總像素上限約 829 萬（4K），也可輸出 PNG、WebP 透明背景。GPT Image 2.5 另外新增 xhigh 與 max 兩個畫質等級，官方文件並註明 2.5 版超過 2560×1440 的解析度仍屬實驗性功能<Cite k="oai-image-guide" />。Wikipedia 整理指出，2.5 版把生成延遲縮短約一半，並在 ChatGPT 加入把手繪草圖轉成圖片的 Sketch 功能<Cite k="wiki-gpt-image" />。

**以 <Term id="token">token</Term> 計價。** 官方價格為每百萬 tokens：文字輸入 5 美元、圖片輸入 8 美元、圖片輸出 30 美元，Batch 半價<Cite k="oai-pricing" />。實際每張成本取決於尺寸與畫質：以 GPT Image 2 的 1024×1024 為例，low 約 0.006 美元、medium 約 0.053 美元、high 約 0.211 美元<Cite k="oai-image-guide" />。2.5 版的 token 單價與 2 相同，但每張圖消耗的 token 數可能不同。

**已知限制。** 官方文件列出：複雜提示可能要 2 分鐘才完成；文字的精確位置、跨多張圖的角色或品牌一致性、需要精準排版的構圖，仍可能出錯<Cite k="oai-image-guide" />。使用 API 前也可能需要先完成組織驗證。

## 適合與不適合的用途

適合：

- **含大量文字的圖像**：海報、資訊圖表、簡報插圖、菜單等需要正確字樣的設計。
- **既有圖片的修改**：換背景、換場景、局部修圖，Sunburst 主打編輯精準度。
- **與文字工作流程整合**：在 ChatGPT 或 Agent 流程中邊討論邊產生、修改圖片。
- **數量不多但要求品質的素材**：在人類偏好評比中名列前茅。

不適合：

- **大量、低單價的生成**：AA 估算 GPT Image 2.5（max）每千張約 211 美元，<ModelChip id="google-nano-banana" /> 的 Nano Banana 2 約 67 美元、Meta 的 Muse Image 約 10 美元<Cite k="aa-t2i" />。
- **需要自行部署或微調**：GPT Image 只能經 API 使用，可考慮有開放權重版本的 <ModelChip id="bfl-flux" />。
- **影片生成**：OpenAI 的 Sora 2 與 Videos API 已於 2026-09-24 關閉，官方沒有指定替代模型<Cite k="oai-deprecations" />。
- **精準的版面控制**：官方承認構圖與元素定位仍不夠穩定。
