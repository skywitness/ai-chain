## 系列概覽

Command 是加拿大 <CompanyChip id="cohere">Cohere</CompanyChip> 的文字生成模型系列。和多數實驗室追求聊天產品不同，Cohere 一開始就鎖定企業：模型以 <Term id="rag">RAG（檢索增強生成）</Term>、<Term id="function-calling">工具呼叫</Term>、多語言與私有部署為重點，搭配自家的 Embed、Rerank 檢索模型與 North 企業 Agent 平台一起銷售<Cite k="co-models" />。

截至 2026-10-06，主力是 2026-05-20 推出的 **Command A+**。它是 Cohere 第一個<Term id="moe">混合專家（MoE）</Term>模型，把前一代分開發行的推理、視覺、翻譯與 Agent 能力合併進同一組權重，並以 Apache 2.0 開放下載<Cite k="co-cap-blog" />。官方文件形容 Command A+ 是「Command A 家族的最後一個模型」，2026-06-09 推出的程式代理模型 North Mini Code 則被定位為新一代 North 系列的第一個模型<Cite k="co-north-mini-code" />。官方模型總覽另列有同屬 North 系列、總參數 2,180 億的翻譯專用 MoE 模型 North Small Translate（版本代號 09-2026），支援 50 種以上語言<Cite k="co-models" />。

## 特性分析

**小硬體、大模型。** Command A+ 總參數 2,180 億，每個 token 只啟用 250 億個<Term id="active-parameters">啟用參數</Term>。Cohere 只對 MoE 專家層做 4-bit（W4A4）<Term id="quantization">量化</Term>、注意力路徑維持全精度，再用量化感知蒸餾補回品質，因此 1 張 B200 或 2 張 H100 就能執行<Cite k="co-cap-hf" />。官方稱在相同量化與並行條件下，它的輸出速度比 111B 稠密的 Command A Reasoning 快最多 63%<Cite k="co-cap-blog" />。

**企業 Agent 導向。** Command A+ 支援影像輸入、工具呼叫與可開關的思考模式，上下文 128K、最長輸出 64K，語言從 23 種擴充到 48 種<Cite k="co-cap-docs" />。官方在 North 平台的內部評測中，Agent 問答與試算表分析分別比 Command A Reasoning 進步 20% 與 32%，但這是以 LLM 評審打分的自家測試<Cite k="co-cap-blog" />。

**授權轉向。** Command A、A Vision、A Reasoning、A Translate 的權重都以 CC-BY-NC 4.0 釋出，只能非商用；Command A+ 與 North Mini Code 改為 Apache 2.0，是 Cohere 開放策略的明顯轉變<Cite k="co-cap-docs" />。

**價格與取得方式。** 官方定價頁把 Command A+ 標為免費，舊款 Command R7B 每百萬 tokens 輸入 0.0375、輸出 0.15 美元<Cite k="co-pricing" />。不過試用金鑰每月限 1,000 次呼叫，官方也說明生產金鑰在 Command A+ 等新變體上比照試用金鑰，正式用量需洽業務<Cite k="co-rl" />。

## 適合與不適合的用途

適合：

- **主權與合規要求高的企業**：可在地端、私有雲或斷網環境部署；2026-10-05 推出的 North 2 平台主打這類部署<Cite k="co-north2" />。
- **企業知識庫 RAG 與工具呼叫**：Command 系列長期針對這些情境訓練。
- **多語言工作**：48 種語言的 Command A+，或專做翻譯的 Command A Translate。
- **GPU 預算有限的自建團隊**：2 張 H100 即可執行旗艦模型。

不適合：

- **需要頂尖推理或程式能力**：AA 智慧指數 13.1，前沿模型多在 50 分以上。
- **長程程式代理**：AA 實測 Terminal-Bench 4.0 僅 0.5%。
- **想要穩定低價、按量付費的公開 API**：新模型的正式用量要走業務洽談或 Model Vault。

## 評測解讀

<Callout type="info" title="同一個指數，兩個數字">Cohere 在 2026-05-20 的發表文中寫 Command A+ 的 AA 智慧指數為 37；2026-10-06 的 AA 頁面則顯示 13.1。同一個模型分數差這麼多，應主要來自 AA 指數改版：現行 v4.3.2 改由 Terminal-Bench 4.0、GDPval-AA、AutomationBench-AA 等 10 項偏重長程 Agent 的評測組成，分數尺度與舊版不同，不能直接比較<Cite k="aa-cap" />。</Callout>

| 評測 | Command A+ | 前代對照 | 來源 |
|---|---|---|---|
| AA 智慧指數 v4.3.2 | 13.1 | Command A 7.0（估計） | AA |
| τ²-Bench Telecom | 85%（自報）／80.7%（AA） | A Reasoning 37%（自報） | 官方、AA |
| Terminal-Bench | Hard 25%（自報）／4.0 版 0.5%（AA） | A Reasoning Hard 3% | 官方、AA |
| MMMU | 75.1%（自報） | A Vision 65.3% | 官方 |
| LMArena 文字榜 | 尚未上榜 | Command A 1354（第 209 名） | LMArena |

AA 數值取自 Cohere 彙整頁<Cite k="aa-cohere" />，LMArena 為 2026-10-02 更新<Cite k="arena-text" />。解讀重點：

- **世代進步是真的**：不論官方或 AA，Command A+ 在客服類 Agent（τ²-Bench）都比前代大幅進步，AA 實測的 80.7% 與官方 85% 相去不遠。
- **評測版本差異很大**：官方的 Terminal-Bench Hard 25% 與 AA 的 Terminal-Bench 4.0 只有 0.5%，是不同版本、不同難度的題組，不代表任何一方有誤；AA 自己量測的 Terminal-Bench Hard 同樣是 25%<Cite k="aa-cap" />。這也顯示它在最新、最難的終端機任務上幾乎無法完成。
- **定位要對**：Command A+ 主打的是「能在 2 張 GPU 上跑、可商用的企業 Agent 模型」，和前沿閉源模型比通用智慧並不公平；選型時應以自家 RAG 與工具流程實測為準。
