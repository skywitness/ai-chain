## 系列概覽

Gemini 是 <CompanyChip id="alphabet">Alphabet</CompanyChip> 旗下 Google DeepMind 開發的閉源<Term id="frontier-model">前沿模型</Term>系列，從第一代起就以<Term id="multimodal">原生多模態</Term>為核心：同一個模型可以直接讀文字、圖片、音訊、影片與 PDF。Gemini 3 系列的基礎模型 Gemini 3 Pro 採用稀疏 <Term id="moe">MoE</Term> 架構，並在自研的 <Term id="tpu">TPU</Term> 上訓練<Cite k="gemini-3-pro-model-card" />。Gemini 也是 Gemini App、搜尋 AI 模式與 Google Cloud 的底層模型；Alphabet 在 2026 年第二季法說會表示，Gemini App 月活躍用戶達 9.5 億，模型 API 每分鐘處理約 220 億個 Token<Cite k="alphabet-q2-2026" />。

產品線大致分三層：追求最強能力的 Pro 與旗艦（目前是 Gemini 4 Argon）、兼顧速度與成本的 Flash，以及大量呼叫用的 Flash-Lite。圖像生成另以 <ModelChip id="google-nano-banana">Nano Banana</ModelChip> 為品牌，開放權重則由 <ModelChip id="google-gemma">Gemma</ModelChip> 負責。

## 特性分析

- **長上下文**：3.x 主力型號的<Term id="context-window">上下文視窗</Term>為 1,048,576 Token、輸出上限 65,536 Token<Cite k="gemini-api-models" />；Gemini 4 Argon 則把輸出上限從前代的 64K 一口氣拉到約 100 萬 Token，讓模型能在單次任務中長時間推理、一次寫完大型程式或長篇證明<Cite k="argon-blog" />；這需要開啟長解碼模式，且輸入與輸出共用約 105 萬 Token 的上下文<Cite k="argon-model-card" />。
- **推理強度可調**：Gemini 3 之後的型號都是<Term id="reasoning-model">推理模型</Term>，開發者以 thinking level 調整思考量。3.7 與 3.8 Flash 已不支援最低的 minimal 等級，Google 也坦言 3.8 Flash 會「更努力」、在高強度下用掉更多 Token<Cite k="gemini-38-blog" />。
- **Flash 快速迭代**：3.6、3.7、3.8 Flash 在六週內連發三版，並以每百萬 Token 輸入 0.75 美元、輸出 3.75 美元的試行價（至 2026 年底）爭取 <Term id="agent">Agent</Term> 與程式開發用量<Cite k="gemini-api-pricing" />。
- **資安取向**：3.8 Flash Cyber 與 Gemini 4 Argon 都主打找出並修補漏洞的防禦能力，先透過 Fairwind 計畫提供給受信任的防禦者<Cite k="argon-blog" />，呼應<TrendLink id="frontier-cyber-capabilities">前沿模型資安能力</TrendLink>的趨勢。
- **計費選項多**：除了標準層，Gemini API 另有 Batch（約五折）、Flex 與 Priority 層。以 3.8 Flash 為例，Batch 與 Flex 為輸入 0.375、輸出 1.875 美元（試行期價格）；長提示可搭配 context caching，快取輸入價約為標準輸入價的一成<Cite k="gemini-api-pricing" />。
- **通路最廣**：3.8 Flash 同時上架 Gemini App、搜尋 AI 模式、Google AI Studio、Gemini API 與企業 Agent 平台<Cite k="dm-gemini-flash" />，其中 Gemini App 與搜尋 AI 模式先開放給 Google AI Pro、Ultra 付費訂閱者<Cite k="gemini-38-blog" />，消費者與開發者用的是同一代模型。

## 適合與不適合的用途

**適合**：一次讀完長合約、整個程式碼庫或長影片的分析工作；大量呼叫的 Agent 與程式開發流程，Flash 線在成本與速度上有優勢；已在 Google Cloud、Workspace、Android 生態系內的企業，整合成本較低。

**不適合或需留意**：

- 想立刻用上最強模型的開發者：Argon 截至 2026-10-06 仍是有限預覽，Gemini API 定價頁上唯一的 Pro 型號仍是 3.1 Pro Preview<Cite k="gemini-api-pricing" />。
- 需要長期固定版本的系統：Gemini 3 Pro Preview 上線不到四個月就在 2026-03-09 關閉，2.5 系列自 2026-09-18 起只開放給既有使用者<Cite k="gemini-api-deprecations" />，遷移成本不可忽視。
- 需要自行部署或微調權重的場景，應改看開放權重的 Gemma。

<Callout type="tip" title="Pro、Flash、Flash-Lite 怎麼選">
多數應用可先以 3.8 Flash 當預設；需要極低延遲、大量分類或翻譯時改用 Flash-Lite（3.5 Flash-Lite 每百萬 Token 輸入 0.30 美元、輸出 2.50 美元）；只有 Flash 明顯答不好的高難度推理，再考慮 3.1 Pro Preview，或等待 Argon 正式開放。選型前最好用自己的資料實測，因為各型號的 Token 用量差異很大。
</Callout>
