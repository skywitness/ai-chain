## 系列概覽

MAI 是 <CompanyChip id="microsoft">微軟（Microsoft）</CompanyChip> 旗下 Microsoft AI 團隊自行訓練的模型家族。2025-08-28，微軟發表第一個端到端自行訓練的基礎模型 MAI-1-preview 與語音模型 MAI-Voice-1，同時表示產品仍會混用自家、合作夥伴與開源社群的最佳模型<Cite k="mai-first-models" />。2026-06-02 的 Build 大會上，微軟一次發表七個新模型，涵蓋推理、程式、影像、語音與轉錄，並把目標定為「人本超級智慧」（Humanist Superintelligence）；除了 Microsoft Foundry 與自家產品，微軟也表示這些模型將陸續上架 OpenRouter、Fireworks 與 Baseten 等第三方平台<Cite k="mai-build-2026" />。

目前的旗艦是推理模型 MAI-Thinking-1，於 Microsoft Foundry 公開預覽<Cite k="mai-thinking-1" />。MAI 的策略重點不在搶排行榜第一，而是在 Copilot、GitHub、Excel 等自家產品中，用更小、更便宜的模型取代部分外部模型呼叫。

## 特性分析

- **中型 MoE 推理模型**：MAI-Thinking-1 是總參數約 1 兆、每個 token 啟用 350 億參數的稀疏 <Term id="moe">MoE</Term>，上下文 256K，相容 Chat Completions API<Cite k="mai-thinking-1" />。<Term id="active-parameters">啟用參數</Term>少，代表推論時需要的運算較少、成本較低。
- **不蒸餾、資料可追溯**：微軟強調 MAI 推理模型從頭訓練，不從其他實驗室的模型<Term id="distillation">蒸餾</Term>，訓練資料乾淨、可追溯<Cite k="mai-thinking-1" />。這對重視來源與合規的企業有吸引力，但也代表無法靠模仿前沿模型快速追趕。
- **在產品裡「爬坡」**：MAI 把模型放進 GitHub Copilot、Excel 等真實產品的強化學習環境持續訓練。官方稱 MAI-Code-1-Flash（50 億啟用參數）在 VS Code 的程式碼接受率比 GPT-5.4 Mini 與 Claude Haiku 4.5 高約 10%<Cite k="mai-copilot-excel" />；1.1 版再把價格降到 1.0 版的四分之一<Cite k="mai-code-1-1" />。
- **價格**：依 Azure 價目，MAI-Thinking-1 全球部署每百萬 token 輸入 2 美元、快取輸入 0.20 美元、輸出 8 美元；MAI-Code-1.1-Flash 為輸入 0.20 美元、輸出 1.20 美元<Cite k="azure-mai-pricing" />。
- **軟硬體協同**：微軟表示 MAI 與自家 Maia 200 加速器協同設計，已看到 1.4 倍的效率提升<Cite k="mai-build-2026" />。延伸閱讀：<TrendLink id="custom-asic-rise">客製化 ASIC 崛起</TrendLink>。

## 適合與不適合的用途

**適合**：已在 Azure／Microsoft Foundry 上、重視成本與資料來源可追溯的企業推理與文件工作；GitHub Copilot 裡的日常程式協助；微軟生態系內的語音合成、轉錄與影像生成，例如 MAI-Transcribe-2 上市時的限時優惠價為每小時音訊 0.10 美元（至 2026 年底）<Cite k="mai-transcribe-2" />。

**不適合**：需要最前沿推理或長時程 Agent 的任務——官方表格中 MAI-Thinking-1 的 Terminal-Bench 2.0 為 46.0%，明顯低於 Claude Opus 4.6 的 65.4%<Cite k="mai-thinking-1" />；需要 1M token 以上上下文的場景；需要下載權重自行部署的需求（MAI 不開放權重）。若只是要比較封閉與開放模型的取捨，可參考 <LearnLink id="open-vs-closed-models">開放權重 vs 封閉模型</LearnLink>。

## 評測解讀

MAI-Thinking-1 目前只有微軟自報的數字（對手數字由微軟取自各家官方模型卡）<Cite k="mai-thinking-1" />：

| 評測 | MAI-Thinking-1 | Claude Opus 4.6 | Kimi K2.6 |
|---|---|---|---|
| GPQA Diamond | 84.2% | 91.3% | 90.5% |
| SWE-bench Verified | 73.5% | 80.8% | 80.2% |
| SWE-bench Pro | 52.8% | 53.4% | 58.6% |
| Terminal-Bench 2.0 | 46.0% | 65.4% | 66.7% |
| AIME 2025 | 97.0% | 99.8% | 未公布 |

解讀重點：

- **對照組是上一代**：表中比較的是 2026 年初的 Opus 4.6、Sonnet 4.6 與 <ModelChip id="moonshot-kimi">Kimi</ModelChip>、<ModelChip id="deepseek">DeepSeek</ModelChip> 等，而不是 2026-09 的 Opus 5.5。即使如此，MAI-Thinking-1 在多數項目仍落後。
- **強項與弱項分明**：數學競賽分數高，SWE-bench Pro 與 Opus 4.6 接近，但需要多步驟操作終端機的 Agent 任務差距明顯，符合「中量級」定位。
- **缺乏第三方評測**：本站 2026-10-06 讀取的 Artificial Analysis 排行榜與 2026-10-02 的 Arena 文字榜都沒有列出 MAI-Thinking-1，因此本頁的能力座標是編輯估計值，而非計算值。
- **人類偏好評測**：微軟與 Surge 合作做了 1,276 題盲測，受評者偏好 MAI-Thinking-1 勝過 Claude Sonnet 4.6，但這是單一合作方的評測，未公布完整勝率<Cite k="mai-thinking-1" />。延伸閱讀：<LearnLink id="model-evaluation">模型評測</LearnLink>。
