## 系列概覽

<CompanyChip id="anthropic">Anthropic</CompanyChip> 的 Claude 是封閉權重的大型語言模型系列，依能力與價格分成幾條產品線：Fable（最高階）、Opus（官方預設推薦的主力）、Sonnet（速度與能力的平衡點）與 Haiku（最快、最便宜）；另有能力與 Fable 相同、但只提供給通過 Anthropic 驗證計畫（網路安全、生命科學）之機構的 Mythos<Cite k="fable-5-1" />。截至 2026-10-06，官方模型總覽建議多數工作先從 Claude Opus 5.5 開始，評測後仍不夠的困難長時程任務才改用 Fable 5.1<Cite k="claude-overview" />。

所有現行模型都支援文字與影像輸入、文字輸出與工具呼叫，並同時上架 Claude API、Amazon Bedrock、Google Cloud 與 Microsoft Foundry<Cite k="claude-overview" />。換句話說，Claude 同時出現在三大雲端的模型目錄中，企業不必搬家就能採用，這也讓它成為 <SegmentChip id="foundation-models" /> 與 <SegmentChip id="cloud-neocloud" /> 兩個環節交會處的重要商品。

## 特性分析

- **程式與 Agent 是核心強項**：Claude 的定位集中在長時間、多步驟的 <Term id="agent">Agent</Term> 工作。Anthropic 公布 Opus 5.5 在 Terminal-Bench 4.0 得到 66.4%、OSWorld 2.1 為 81.8%（部分給分）<Cite k="opus-5-5" />；Sonnet 5.5 的 Terminal-Bench 4.0 則為 70.6%<Cite k="sonnet-5-5" />。
- **長上下文**：Opus、Sonnet、Fable 5.x 都提供 1M token 的 <Term id="context-window">上下文視窗</Term> 與 128K 輸出上限；Haiku 4.5 為 200K<Cite k="claude-overview" />。
- **自適應思考**：新世代由模型自行決定要想多久，開發者以 effort（low 到 max）調整深度。Opus 5.5 的思考無法關閉、預設 effort 為 medium<Cite k="claude-overview" />。這是典型的 <Term id="test-time-compute">推論時運算</Term> 取捨：想得越久通常越準，但也越貴、越慢。
- **價格持續下探**：Opus 等級每百萬 token 的輸入／輸出價格，從 Opus 4.1 的 15／75 美元降到 Opus 4.5 至 Opus 5 的 5／25 美元，再到 Opus 5.5 的 4／20 美元；Opus 5.5 與 Sonnet 5.5 的 <Term id="prompt-caching">提示快取</Term> 讀取價也降為基礎輸入價的 5%，分別只要 0.20 美元與 0.10 美元<Cite k="claude-pricing" />。Anthropic 稱在預設設定下，Opus 5.5 典型工作的成本比 Opus 5 低 40%，輸出速度快 30% 以上<Cite k="opus-5-5" />。
- **較嚴格的安全機制**：Opus 5.5 附帶與 Fable 5.1 類似的網安與生物安全防護，敏感請求可能被攔下，需要由備援模型接手或申請驗證計畫<Cite k="opus-5-5" />。

## 適合與不適合的用途

**適合**：大型程式碼庫的遷移、稽核與除錯（官方案例中，測試者在不到一天內完成 68 萬行程式碼遷移<Cite k="opus-5-5" />）；長文件、試算表與簡報類知識工作；<Term id="computer-use">電腦操作</Term>與瀏覽器自動化；已在 AWS、Google Cloud 或 Azure 上、希望直接在原平台採用前沿模型的企業。延伸閱讀：<TrendLink id="ai-coding">AI 寫程式</TrendLink>。

**不適合**：需要自行部署、檢視或微調權重的場景（Claude 不開放權重，可參考 <LearnLink id="open-vs-closed-models">開放權重 vs 封閉模型</LearnLink>）；超大量、極低延遲的簡單任務若用 Opus 或 Fable，成本與等待時間都偏高，Haiku 4.5 或更小的開放權重模型可能更省錢；涉及漏洞利用或高風險生物研究的請求，會被安全機制攔下。另外，Haiku 線仍停在 4.5（知識截止 2025 年 2 月），小模型的更新明顯落後大模型<Cite k="claude-overview" />。

## 版本演進

過去 18 個月，Claude 的發布節奏從「半年一代」加快到「每月都有新版本」：

1. **Claude 4 世代**：2025-05-22 推出 Opus 4 與 Sonnet 4<Cite k="claude-4" />，2025-08-05 推出 Opus 4.1<Cite k="opus-4-1" />，2025-09-29 Sonnet 4.5<Cite k="sonnet-4-5" />，2025-10-15 Haiku 4.5，2025-11-24 Opus 4.5（Opus 價格降為 5／25 美元）。
2. **百萬上下文與密集迭代**：2026-02 的 Opus 4.6 與 Sonnet 4.6 把上下文擴大到 1M，之後 4 月 Opus 4.7、5 月 Opus 4.8。
3. **網安模型與新層級**：2026-04-07 Anthropic 以 Mythos Preview 啟動 Project Glasswing，與 AWS、Apple、Google、Microsoft、NVIDIA 等合作找出關鍵軟體的漏洞<Cite k="glasswing" />；2026-06-09 推出 Fable 5 與 Mythos 5，形成 Opus 之上的新層級，接著是 6 月底的 Sonnet 5 與 7 月的 Opus 5。
4. **5.5 世代**：2026-09-01 Fable 5.1／Mythos 5.1（快取讀取降到每百萬 token 0.25 美元）<Cite k="fable-5-1" />，9-22 Opus 5.5，9-28 Sonnet 5.5；Anthropic 表示 Haiku 5.5 將在未來幾週推出<Cite k="sonnet-5-5" />。

退役方面，Opus 4 與 Sonnet 4 已於 2026-06-15 在 Claude API 退役，Opus 4.1 於 2026-08-05 退役，Sonnet 4.5 預定 2026-11-30 退役<Cite k="claude-deprecations" />。

## 評測解讀

| 指標（日期） | Opus 5.5 | Sonnet 5.5 | Fable 5.1 | 來源性質 |
|---|---|---|---|---|
| AA 智慧指數 v4.3.2（2026-10-06） | 58 | 56 | 53 | 第三方 |
| Arena 文字榜 Elo（2026-10-02） | 1,504 | 1,471 | 1,501 | 人類盲測投票 |
| Terminal-Bench 4.0（2026-09） | 66.4% | 70.6% | 55.8% | 廠商自報 |
| HLE，含工具（2026-09） | 67.7% | 64.5% | 65.6% | 廠商自報 |

解讀時有幾點要注意：

- **第三方指數**：Artificial Analysis 的前兩名都是 Claude，但它測的是「max effort、含預設備援」的設定，而且 v4.3 才把 Terminal-Bench 換成 4.0 並加入 AutomationBench，不同版本的指數不能直接相比<Cite k="aa-leaderboard" />。
- **<Term id="elo-rating">Elo 分數</Term>的誤差**：Arena 上 Opus 5.5 為 1,504 ±9，與 Opus 4.6（1,505）、Fable 5（1,504）幾乎重疊，且票數只有約 4,500 票，排名仍可能變動<Cite k="arena-text" />。Arena 反映的是一般對話偏好，和 Agent 能力不完全相關。
- **廠商自報分數**：Anthropic 自己也提醒，在這個能力水準下，評測差距已不太能反映真實差異，Opus 5.5 與 Fable 5.1 的實際落差比分數小；Opus 5.5 測試時開啟正式安全機制，被攔下的網安任務改由 Opus 4.8 完成，可能壓低分數<Cite k="opus-5-5" />。同一張表中，<ModelChip id="openai-gpt">OpenAI GPT</ModelChip> 的 GPT-6 Astra 在 Terminal-Bench 4.0 為 57.9%（OpenAI 自報）<Cite k="opus-5-5" />。同一個模型在不同發表文中的數字也可能略有出入，例如 Fable 5.1 的 HLE（含工具）在自家發表文中為 65.0%<Cite k="fable-5-1" />，在 Opus 5.5 發表文的對照表中則是 65.6%。
- **單一評測不代表整體**：Sonnet 5.5 的 Terminal-Bench 4.0 高於 Opus 5.5，但 Anthropic 仍表示 Opus 5.5 在需要持續判斷的開放式工作上明顯較強<Cite k="sonnet-5-5" />。想進一步了解評測方法，可閱讀 <LearnLink id="model-evaluation">模型評測</LearnLink>。
