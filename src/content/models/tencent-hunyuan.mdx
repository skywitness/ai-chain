## 系列概覽

混元是<CompanyChip id="tencent">騰訊（Tencent）</CompanyChip>的基礎模型家族，2023 年 9 月首度透過騰訊雲提供給企業客戶<Cite k="wiki-hy" />。騰訊也持續釋出開放權重模型，例如 2025-06-27 開源的 Hunyuan-A13B（總參數 800 億、啟用 130 億），騰訊雲稱它是混元第一個可切換快慢思考的混合推理模型<Cite k="hf-a13b" /><Cite k="tc-cloud-models" />。2026 年起國際品牌縮短為 Hy，中國市場仍沿用混元之名<Cite k="wiki-hy" />。

真正的轉折在 2026 年：騰訊表示從年初起重建預訓練與強化學習基礎設施（Hy3 preview 新聞稿寫 2 月起，Hy3 新聞稿則寫 1 月底），4 月推出的 Hy3 preview 就是新設施產出的第一個模型<Cite k="tc-hy3p" /><Cite k="tc-hy3" />。Hy3 於 2026-07-06 正式發布<Cite k="tc-hy3" />，Hy4 preview 於 2026-08-28 開源，總參數由 2,950 億擴大到 7,700 億<Cite k="tc-hy4" />。同一個 GitHub 組織下還有 HunyuanImage、HunyuanVideo、Hunyuan3D、HY-World 等生成模型與翻譯模型 Hy-MT<Cite k="gh-org" />，本頁聚焦語言模型。

## 特性分析

- **大型 <Term id="moe">MoE</Term>，啟用參數小**：Hy3 總參數 295B，每個 token 只啟用 21B（192 個專家選 8 個），另有 3.8B 的 MTP 層<Cite k="hf-hy3" />。Hy4 preview 擴大到 770B 總參數、49B <Term id="active-parameters">啟用參數</Term>，78 層中有 77 層為 MoE，每層 256 個路由專家加 1 個共享專家<Cite k="hf-hy4" />。
- **長上下文與稀疏注意力**：Hy3 支援 256K <Term id="context-window">上下文</Term>；Hy4 preview 借鏡 DeepSeek 與 GLM，採 Gated DSA <Term id="sparse-attention">稀疏注意力</Term>，上下文約 100 萬 tokens，並內建 MTP 層做<Term id="speculative-decoding">推測解碼</Term><Cite k="hf-hy4" />。
- **快慢思考可切換**：兩代都是混合型<Term id="reasoning-model">推理模型</Term>。Hy3 預設直接回答，可把推理強度設為 low 或 high；Hy4 preview 預設 high，也能切換成不思考模式<Cite k="hf-hy3" /><Cite k="hf-hy4" />。
- **授權轉向寬鬆**：Hy3 preview 採騰訊社群授權，明定不適用於歐盟、英國與南韓，月活躍使用者逾 1 億的業者須另行申請<Cite k="hf-hy3p" />；Hy3 與 Hy4 preview 改為 Apache 2.0<Cite k="tc-hy3" /><Cite k="hf-hy4" />。
- **產品驅動的後訓練**：騰訊稱 Hy3 依 50 多個產品的回饋擴大後訓練，內部評測的幻覺率從 12.5% 降到 5.4%<Cite k="hf-hy3" />；Hy3 已用於 WorkBuddy／CodeBuddy、元寶、ima 與微信公眾號客服<Cite k="tc-hy3" />。

## 適合與不適合的用途

**適合**：需要自行部署、可商用的<Term id="open-weights">開放權重</Term>模型來做程式 Agent、辦公文件處理或金融分析；成本敏感的長文件工作；以及已在騰訊雲、微信生態中的應用。價格方面，騰訊公布 Hy3 在 OpenRouter 的起價為每百萬 tokens 輸入 0.1288、輸出 0.5336 美元<Cite k="tc-hy3-global" />，Hy4 preview 為 0.834／2.501 美元<Cite k="tc-hy4" />。

**不適合**：需要圖片、音訊或影片理解的工作——Hy3 只處理文字輸入與輸出<Cite k="aa-hy3" />；追求最高綜合能力的關鍵任務——Hy4 preview 仍是預覽版，騰訊自己列出推理時間過長、過度自我驗證等已知問題<Cite k="hf-hy4" />；以及缺乏多 GPU 伺服器的團隊——官方建議以 8 張 H20-3e 等級的 GPU 部署 Hy3<Cite k="hf-hy3" />。

從 A13B 到 Hy4，騰訊的路線是「先開源預覽版、收集產品回饋、再推正式版」。騰訊稱 Hy3 preview 上線後日均 token 用量成長 20 倍<Cite k="tc-hy3" />；維基百科引用 OpenRouter 資料指出，截至 2026-09-06 的 7 天內，Hy4 preview 以 14.7 兆 tokens 居該平台用量第一<Cite k="wiki-hy" />。不過 OpenRouter 用量只反映單一平台，且常受免費或低價推廣影響，不能等同於模型品質。

## 評測解讀

第三方評測資料目前只涵蓋 Hy3。Artificial Analysis 智慧指數 v4.3 給 Hy3 打 25 分，明顯高於同級模型的中位數（約 18 至 19），但與榜首 Claude Opus 5.5 的約 58 分差距明顯；其 GPQA Diamond 為 89.7%、Humanity's Last Exam 為 33.5%<Cite k="aa-hy3" />。LMArena 文字榜（投票截至 2026-10-02）上，Hy3 以 1,456 分與字節跳動 <ModelChip id="bytedance-seed">Seed 2.0 Pro</ModelChip> 幾乎同分，比 Hy3 preview 的 1,409 分高約 47 分，顯示正式版的改進確實反映在使用者偏好上<Cite k="arena-text" />。

Hy4 preview 尚未進入 AA 指數，現有<Term id="benchmark">評測</Term>數字都來自騰訊模型卡：GPQA Diamond 92.3%、HLE（不用工具）43.4%、SWE-bench Pro 65.7%、Terminal-Bench 2.1 85.4%，相對 Hy3 的 90.9%、34.4%、57.9%、70.8% 進步明顯<Cite k="hf-hy4" />。解讀時要注意三點：第一，騰訊在同表中重測了 Hy3，部分分數與先前公布的不同；第二，Terminal-Bench 2.1 使用 Claude Code 框架、每題最多 500 輪與 12 小時，設定相當寬鬆；第三，表中其他模型的數字大多由騰訊自行測得，部分欄位同時列出原廠公布值與騰訊重測值，兩者可能差距不小。在這份表格裡，Hy4 preview 與 <ModelChip id="deepseek">DeepSeek V4 Pro</ModelChip>、<ModelChip id="zhipu-glm">GLM-5.3</ModelChip>、<ModelChip id="moonshot-kimi">Kimi K3</ModelChip>、<ModelChip id="alibaba-qwen">Qwen 3.8 Max</ModelChip> 互有勝負，差距多在幾個百分點內。以 Terminal-Bench 2.1 為例，Hy4 preview 的 85.4% 低於這四家原廠公布的 86.6% 至 88.3%；改用騰訊重測值，則只領先 DeepSeek V4 Pro（80.3%），仍低於另外三者（85.7% 至 88.3%）。因此本站把它的能力座標估在中國開放權重第一梯隊的下緣，待第三方評測公布後再更新。
