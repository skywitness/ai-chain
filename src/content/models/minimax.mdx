## 系列概覽

<CompanyChip id="minimax">MiniMax（稀宇科技）</CompanyChip>是少數同時經營語言、影片、語音與音樂模型的中國實驗室：2026 年 7 月推出影片模型 MiniMax H3 與 Music 3.0，語音則有 Speech 2.8<Cite k="mm-relnotes" />。本頁聚焦它的 M 系列語言模型，這條產品線一路以「便宜、能用工具、能寫程式」為賣點。

截至 2026-10-06，官方 API 列出的語言模型如下<Cite k="mm-textgen" /><Cite k="mm-pricing" />：

| 型號 | 上下文 | 每百萬 tokens 價格（輸入／輸出） | 說明 |
|---|---|---|---|
| MiniMax-M3.1-Flash-Preview | 100 萬 | 未公布 | 僅限 M Plan 訂閱與 MiniMax Code |
| MiniMax-M3 | 100 萬 | 0.30／1.20 美元（512K 以內） | 旗艦，輸出約每秒 100 tokens 以上 |
| MiniMax-M2.7 | 204,800 | 0.30／1.20 美元 | 輸出約每秒 60 tokens，另有高速版 |
| M2.5、M2.1、M2 | 204,800 | 0.30／1.20 美元 | 列為舊版 |

官方文件把 M3.1-Flash-Preview 列為最新的 M 系列模型，但目前只透過 M Plan 訂閱金鑰與 MiniMax Code 提供<Cite k="mm-textgen" />；據媒體報導它於 2026-09-27 推出，官方至今未公布價格、參數與評測<Cite k="datanorth-m31" />。

## 特性分析

**低價與 Agent 定位。** 2025 年 10 月的 M2 是總參數 2,300 億、每個 token 只啟用 100 億的 <Term id="moe">MoE</Term>，官方強調小的<Term id="active-parameters">啟用參數</Term>能降低延遲與成本，專為程式與 <Term id="agent">Agent</Term> 工作流設計<Cite k="hf-minimax-m2" />。從 M2 到 M3，標準 API 價格都維持在每百萬 tokens 輸入 0.30 美元、輸出 1.20 美元；其中 M3 是輸入 512K 以內、官方標示原價「永久五折」後的價格<Cite k="mm-pricing" />。

**MSA 稀疏注意力撐起百萬上下文。** M3 採自研的 MiniMax Sparse Attention，把 KV 切成區塊並只計算被選中的部分。官方稱在 100 萬 tokens 下，每個 token 的運算量只有前代的 1/20，prefill 與 decode 分別加速 9 倍與 15 倍以上<Cite k="mm-m3-blog" />。這屬於<Term id="sparse-attention">稀疏注意力</Term>路線，與 DeepSeek 的 DSA 同樣是先篩選、再計算；官方稱 MSA 切分 KV 區塊更精細，能涵蓋更多有效上下文<Cite k="mm-m3-blog" />。

**原生多模態與長程任務。** M3 從訓練第一步就混合文字、圖片與影片，也能操作桌面電腦<Cite k="mm-m3-blog" />。官方展示 M3 連續執行約 24 小時、呼叫工具 1,959 次，把 Hopper GPU 上 FP8 矩陣乘法核心的硬體峰值使用率由 7.6% 提升到 71.3%<Cite k="mm-m3-page" /><Cite k="mm-m3-blog" />。

**授權逐步收緊。** M1 採 Apache 2.0，M2 到 M2.5 為修改版 MIT；M2.7 改為非商用授權，商用須事先取得書面授權並標示「Built with MiniMax M2.7」<Cite k="mm-m27-license" />；M3 的 MiniMax Community License 允許非商用免費使用，商用必須標示「Built with MiniMax M3」並通知 MiniMax，年營收超過 2,000 萬美元者須事先取得書面授權，且禁止軍事用途<Cite k="mm-m3-license" />。

**敢說不知道。** AA 的知識測驗中，M3 遇到不會的題目多半選擇不答，<Term id="hallucination">幻覺</Term>率約 18%，明顯低於 Kimi K3 與 DeepSeek V4.1-Flash；但答對率也只有約 17%<Cite k="aa-minimax-m3" />。

## 適合與不適合的用途

適合：

- **大量工具呼叫的自動化流程**：AA 量測 M3 的 τ²-bench 為 88.9%，搭配低價，適合客服、資料整理等需要反覆<Term id="function-calling">呼叫函式</Term>的 Agent<Cite k="aa-minimax-m3" />。
- **長文件、長影片與大型程式碼庫**：100 萬 tokens 上下文，512K 以內不加價。
- **研究與教學的本地部署**：權重在 Hugging Face 可下載，非商用用途免費。

不適合：

- **需要前沿綜合能力的任務**：M3 的 AA 綜合智慧指數 29，低於 <ModelChip id="deepseek" />（39）與 <ModelChip id="moonshot-kimi" />（44）<Cite k="aa-leaderboard" />。
- **知識密集的問答**：答對率偏低，宜搭配 <LearnLink id="rag-and-vector-search">RAG</LearnLink>。
- **想直接商用自架的新創或企業**：M2.7 與 M3 都需要通知或取得授權，法務成本比 MIT 授權的模型高。
- **需要穩定 API 的最新版本**：M3.1-Flash-Preview 只在自家工具與訂閱方案中提供。
