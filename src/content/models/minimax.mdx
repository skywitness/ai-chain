## 系列概覽

<CompanyChip id="minimax">MiniMax（稀宇科技）</CompanyChip>是少數同時經營語言、影片、圖像、語音與音樂模型的中國實驗室：2026 年 7 月推出影片模型 MiniMax H3，11 月再發表開放權重的圖像模型 H3 Image<Cite k="mm-relnotes" />。本頁聚焦它的 M 系列語言模型，這條產品線一路以「便宜、能用工具、能寫程式」為賣點。

2026-11-13 讀取時，官方 API 的語言模型只剩兩款，M2 系列則陸續退役<Cite k="mm-model-list" /><Cite k="mm-pricing" />：

| 型號 | 上下文 | 每百萬 tokens 價格（輸入／輸出） | 狀態 |
|---|---|---|---|
| MiniMax-M3.1-Flash | 100 萬 | 0.15／0.60 美元 | 最新 M 系列模型，2026-10-19 推出 |
| MiniMax-M3 | 100 萬 | 0.30／1.20 美元（512K 以內） | 仍可使用 |
| M2.7、M2.5 | 204,800 | 定價頁已不列出 | 10-19 起不開放新用戶，預定 11-18 退役 |
| M2.1、M2 | 204,800 | 定價頁已不列出 | 官方列為已退役 |

M3.1-Flash 上線後，訂閱制 M Plan 的文字模型全部改用它；先前只在訂閱方案提供的 M3.1-Flash-Preview 也已退役，舊名稱的請求改由正式版處理<Cite k="mm-mplan" />。官方另說，著重能力上限的 Pro 版會稍後推出<Cite k="mm-m31f-blog" />。

## 特性分析

**低價與 Agent 定位。** 2025 年 10 月的 M2 是總參數 2,300 億、每個 token 只啟用 100 億的 <Term id="moe">MoE</Term>，官方強調小的<Term id="active-parameters">啟用參數</Term>能降低延遲與成本<Cite k="hf-minimax-m2" />。M2 到 M3 的標準 API 價格都是每百萬 tokens 輸入 0.30、輸出 1.20 美元；M3.1-Flash 再降一半為 0.15／0.60 美元，而且不分輸入長度，官方稱 Agent 任務的整體使用成本比前代低 70%<Cite k="mm-pricing" /><Cite k="mm-m31f-blog" />。

**MSA 稀疏注意力撐起百萬上下文。** M3 採自研的 MiniMax Sparse Attention，把 KV 切成區塊並只計算被選中的部分；官方稱在 100 萬 tokens 下，每個 token 的運算量只有前代的 1/20<Cite k="mm-m3-blog" />。這屬於<Term id="sparse-attention">稀疏注意力</Term>路線，與 DeepSeek 的 DSA 同樣是先篩選、再計算。

**M3.1-Flash：一樣大，跑得更省。** M3.1-Flash 與 M3 同為約 4,280 億參數、每個 token 啟用 230 億，主要改了三件事：把前三層全注意力也換成稀疏注意力、訓練時就把專家與注意力路徑<Term id="quantization">量化</Term>，以及改用 DSpark <Term id="speculative-decoding">推測解碼</Term><Cite k="hf-minimax-m31f" />。官方稱日常輸出速度可達每秒 200 tokens 以上，匿名測試代號 Space Bunny 的早期版本處理過超過 200 兆 tokens<Cite k="mm-m31f-blog" />。不過 AA 量測它跑綜合指數時共輸出約 1.61 億 tokens，首個答案 token 約需 55 秒，屬於想得久、寫得多的模型<Cite k="aa-minimax-m31f" />。

**原生多模態與長程任務。** M3 從訓練第一步就混合文字、圖片與影片，也能操作桌面電腦<Cite k="mm-m3-blog" />；官方展示 M3 連續執行約 24 小時、呼叫工具 1,959 次，把 Hopper GPU 上 FP8 矩陣乘法核心的硬體峰值使用率由 7.6% 提升到 71.3%<Cite k="mm-m3-page" />。

**授權逐步收緊。** M1 採 Apache 2.0，M2 到 M2.5 為修改版 MIT；M2.7 改為非商用授權<Cite k="mm-m27-license" />。M3 與 M3.1-Flash 的 MiniMax Community License 允許非商用免費使用，商用必須標示「Built with MiniMax」加上型號並通知 MiniMax，年營收超過 2,000 萬美元者須事先取得書面授權，且禁止軍事用途<Cite k="mm-m3-license" /><Cite k="mm-m31f-license" />。M3.1-Flash 發表當天官方說權重稍後釋出，Hugging Face 儲存庫的首次提交日期是 2026-10-23<Cite k="hf-minimax-m31f" />。

## 適合與不適合的用途

適合：

- **大量工具呼叫的自動化流程**：AA 量測 M3 的 τ²-bench 為 88.9%，M3.1-Flash 價格再減半，適合客服、資料整理等需要反覆<Term id="function-calling">呼叫函式</Term>的 <Term id="agent">Agent</Term><Cite k="aa-minimax-m3" />。
- **長文件、長影片與大型程式碼庫**：100 萬 tokens 上下文，M3.1-Flash 不分長度同價。
- **自架部署**：權重在 Hugging Face 可下載，官方提供 SGLang 部署指引，M3.1-Flash 的實驗性方案以 4 張 B300 為基準<Cite k="mm-local-deploy" />。

不適合：

- **需要前沿綜合能力的任務**：M3.1-Flash 的 AA 綜合智慧指數 v5.0.1 為 29，低於 <ModelChip id="deepseek" /> 的 V4.1 Flash（33）與 <ModelChip id="zhipu-glm" /> 的 GLM-5.3（32）<Cite k="aa-leaderboard" />。
- **知識密集的問答**：AA-Omniscience v1.1 中，M3.1-Flash 沒答對的題目約 94% 是給出錯誤答案，而不是表示不知道，宜搭配 <LearnLink id="rag-and-vector-search">RAG</LearnLink><Cite k="aa-minimax-m31f" />。
- **要求即時回應的介面**：首個答案 token 動輒數十秒，聊天等互動場景宜調低推理強度。
- **仍在使用 M2.5 或 M2.7 API 的系統**：隨用隨付 API 預定 2026-11-18 停止服務，需要盡快遷移<Cite k="mm-model-list" />。
