## 系列概覽

LongCat（龍貓）是<CompanyChip id="meituan">美團（Meituan）</CompanyChip>自研的大型語言模型家族。外送與在地生活平台跨界做基礎模型，美團選擇的路線是「規模大、權重全開放」：2025-08-29 發表並同步開源總參數 5,600 億的<Term id="moe">混合專家（MoE）</Term>模型 LongCat-Flash-Chat，9 月 5 日開放 API 平台<Cite k="lc-changelog" /><Cite k="lc-flash-report" />。之後一年陸續推出推理版 Flash-Thinking、全模態 Flash-Omni、輕量版 Flash-Lite、Lean4 定理證明專用的 Flash-Prover，以及原生多模態研究模型 LongCat-Next，主力模型幾乎都以 MIT 授權開放<Term id="open-weights">權重</Term><Cite k="hf-org" />。

2026 年起 LongCat 改走兆級路線。4 月 20 日開放 LongCat-2.0-Preview 限量測試；5 月 29 日為了集中資源，一次停止 Flash-Chat、Flash-Thinking、Flash-Lite 等 6 個舊模型的 API 服務；6 月 30 日正式推出總參數 1.6 兆的 LongCat-2.0 並開始收費<Cite k="lc-changelog" />。9 月 25 日上線的 LongCat-2.5-Preview 新增圖片理解，11 月 2 日推出正式版 LongCat-2.5，權重同樣以 MIT 授權放上 Hugging Face<Cite k="lc-changelog" /><Cite k="hf-lc25" />。截至 2026-11-13，API 文件列出的模型只剩 LongCat-2.5 一個<Cite k="lc-quickstart" />。

同一個團隊也開源影片生成 LongCat-Video、圖像生成 LongCat-Image、語音合成 LongCat-AudioDiT 與數位人 LongCat-Video-Avatar 等模型<Cite k="hf-org" />，本頁只追蹤語言模型。

## 特性分析

- **依 token 調整算力的 MoE**：Flash 系列總參數 5,600 億，以「零計算專家」讓不重要的 token 少用算力，每個 token 啟用 186 億到 313 億參數（平均約 270 億）；再以 ScMoE 設計讓運算與通訊重疊，官方稱推論速度逾每秒 100 tokens<Cite k="hf-flash-chat" />。
- **用嵌入表取代部分專家**：Flash-Lite 把 300 多億參數放進 N-gram 嵌入表，總參數 685 億、每次只啟用約 30 億，官方稱比同等參數的純 MoE 更好也更快；LongCat-2.0 沿用這個設計，內含 1,350 億 N-gram 嵌入參數<Cite k="hf-lite" /><Cite k="hf-lc20" />。
- **LongCat 稀疏注意力（LSA）**：以 <ModelChip id="deepseek">DeepSeek</ModelChip> 的 DSA 為基礎改良的<Term id="sparse-attention">稀疏注意力</Term>，加入串流友善索引、相鄰層共用索引與先粗後細的兩段式篩選，用來壓低百萬 token 長上下文的成本。LongCat-2.0 首度採用，並以數千億 tokens 的 1M 上下文資料訓練；7 月底的 Flash-Lite-Sparse 把同一套機制放進輕量模型<Cite k="hf-lc20" /><Cite k="hf-lite-sparse" />。
- **把影像變成 token**：LongCat-2.5 沿用 LongCat-Next 的做法，以殘差向量量化把原生解析度的影像特徵轉成多層離散 token，讓主幹模型用處理文字的方式處理圖片，屬於<Term id="multimodal">多模態</Term>模型中較少見的「離散化」路線；API 可同時輸入圖片與影片<Cite k="lc25-blog" /><Cite k="hf-next" /><Cite k="lc-vision" />。
- **長程 Agent 訓練**：LongCat-2.5 把 GitHub PR 與內部工程任務自動轉成可驗證的訓練環境，也把真實 <Term id="agent">Agent</Term> 的失敗軌跡改寫成訓練題，以大規模<Term id="reinforcement-learning">強化學習</Term>提升完整專案開發能力；另由 Agent、推理、互動三組專家模型以<Term id="distillation">蒸餾</Term>方式教學生模型<Cite k="lc25-blog" />。
- **國產算力**：官方稱 LongCat-2.0 的訓練與大規模部署全部建立在 AI ASIC 超節點上；LongCat-2.5 的長上下文訓練在單顆記憶體不到 80 GB 的國產 AI 加速器上完成，並把專家權重與活化值都<Term id="quantization">量化</Term>為 4 位元（W4A4），在國產加速器上以原生 INT4 推論。兩者都沒有具名晶片供應商<Cite k="hf-lc20" /><Cite k="lc25-blog" /><Cite k="hf-lc25" />。
- **價格與介面**：LongCat-2.5 的 API 限時優惠價為每百萬 tokens 輸入 0.30、輸出 1.20 美元，快取命中輸入 0.006 美元，與 LongCat-2.0 相同，官方沒有列出原價；上下文 1,048,576 tokens、單次最多輸出 262,144 tokens，並同時相容 OpenAI 與 Anthropic 的 API 格式<Cite k="lc-pricing" /><Cite k="lc-price20" /><Cite k="lc-params" />。

## 適合與不適合的用途

**適合**：成本敏感、需要大量呼叫的程式開發與長程 Agent 流程，官方文件提供 Claude Code、Codex、OpenCode 等工具的接法<Cite k="lc-quickstart" />；需要可商用、可微調的 MIT 授權兆級權重的研究與企業團隊；要看截圖、圖表或影片再寫程式的視覺程式設計，以及官方強調的創意設計與 3D 任務<Cite k="lc25-blog" />。資源有限時，可考慮總參數約 690 億、每次只啟用約 30 億參數的 Flash-Lite-Sparse<Cite k="hf-lite-sparse" />。

**不適合**：需要長期穩定介面的正式系統。LongCat 的 API 汰換很快，2026-05-29 一次停用 6 個模型，而 2026-11-13 的 API 文件只剩 LongCat-2.5 可用，整合時要預留遷移成本<Cite k="lc-changelog" /><Cite k="lc-quickstart" />。現行價格標示為限時優惠，長期成本不確定；中國大陸用戶儲值或購買資源包前，須完成實名或企業認證<Cite k="lc-pricing" /><Cite k="lc-faq" />。想自行部署 LongCat-2.5 的團隊也要注意，模型卡目前只提供 <Term id="npu">NPU</Term> 平台的部署說明，1.6 兆參數的硬體門檻很高<Cite k="hf-lc25" />。

## 評測解讀

Artificial Analysis（AA）在 2026-10-27 把綜合智慧指數改版為 v5（11 月起為 v5.0.1）：新增 2 項評測、升級 3 項、移除 3 項並重訂權重，六成權重改由不公開測試集或不公開答案的評測組成，分數不能與改版前的 v4 互比<Cite k="aa-v5-article" />。截至 2026-11-13，AA 名單上列有 LongCat 2.0 與 LongCat Flash Lite，但都還沒有 v5 綜合分數，LongCat-2.5 則尚未列入；本系列在本站也沒有 v4 分數。因此本頁的能力座標是編輯估計值，以原廠表格中與 LongCat-2.5 相近的 <ModelChip id="zhipu-glm">GLM-5.3</ModelChip>（Max 推理強度，v5.0.1 為 32 分）與 DeepSeek V4.1 Flash 1017（Max 推理強度，33 分）為錨點，再保守下修<Cite k="aa-lb" />。

下修的理由有兩個。第一，LongCat-2.5 的所有成績都是原廠自測，例如 Terminal-Bench 2.1 為 88.4%、4.0 版為 38.5%，使用工具的 HLE 為 63.1%<Cite k="hf-lc25" />。第二，AA 已跑完 LongCat 2.0 的部分 v5 子項，其中 Terminal-Bench 4.0 為 0%，與原廠表格中的 3.0% 相近；同一測試 AA 量到 GLM-5.3（max）約 42%、DeepSeek V4.1 Flash 1017（max）約 34%，可見前一代在這項新評測上明顯落後同級<Cite k="aa-lc20" /><Cite k="hf-lc25" />。原廠表格顯示 2.5 在 Terminal-Bench 4.0 由 3.0% 大幅進步到 38.5%，這個跳幅是否成立，要等 AA 等第三方實測確認。

解讀時還要注意三點。其一，同一評測的不同版本落差很大：LongCat-2.5 的 Terminal-Bench 2.1 與 4.0 相差近 50 個百分點，引用時要寫明版本。其二，原廠表格混用自家評測（LongCat AppDev、LongCatClawBench）與剛推出的新<Term id="benchmark">評測</Term>，對照模型的分數有些是引用他人報告、有些是自測，不能直接排名。其三，Arena 文字榜（頁面日期 2026-11-11，共 421 個模型）只收錄第一代 Flash-Chat：已停用的 API 實驗版 LongCat-Flash-Chat Exp（2602）為 1,436 分、排第 104，MIT 原版為 1,401 分、排第 167，2.0 以後的新世代模型還沒有<Term id="elo-rating">Elo 分數</Term><Cite k="arena-text" />。各榜單每週變動，引用時務必附上日期。
