## 系列概覽

DeepSeek 是 <CompanyChip id="deepseek">深度求索（DeepSeek）</CompanyChip>開發的語言模型系列，近年的權重皆以 MIT 授權公開。2025-01-20 推出的推理模型 R1 讓它一舉成名，之後更新節奏很快：2025 年 8 月的 V3.1 把思考與非思考模式合進同一個模型，12 月的 V3.2 導入稀疏注意力；2026-04-24 發布 V4 預覽版，分成 Pro 與 Flash 兩個尺寸<Cite k="ds-changelog" />。

## 特性分析

**長上下文的成本工程。** DeepSeek 的核心路線是把 <Term id="kv-cache">KV Cache</Term> 與注意力運算壓到最低。V3.2 系列導入 DSA <Term id="sparse-attention">稀疏注意力</Term><Cite k="ds-v32exp-news" />；V4 改用壓縮稀疏注意力與重度壓縮注意力的混合設計，官方稱在 100 萬 tokens <Term id="context-window">上下文</Term>下，V4-Pro 單 token 推論運算只需 V3.2 的 27%、KV Cache 只需 10%<Cite k="hf-v4-pro" />。V4.1-Flash 再改成「因果編碼器—解碼器」架構，解碼器的全域 KV Cache 直接由編碼器最後一層的輸出投影而來，不必每層各存一份，官方稱所需 HBM 只有前代的四分之一、SSD 儲存只有八分之一<Cite k="ds-v41-news" />。

**尖離峰計價。** 2026-08-16 起官方 API 改採尖峰與離峰兩種價格，離峰為尖峰的一半。依 2026-11-13 的官方定價頁，deepseek-flash（V4.1-Flash-1017）尖峰每百萬 tokens 輸入 0.30 美元、輸出 1.20 美元，<Term id="prompt-caching">快取</Term>命中只要 0.006 美元，與 9 月版相同；V4-Pro 尖峰為 1.32 與 3.96 美元<Cite k="ds-pricing" />。2026-10-17 起，官方也把自家搜尋引擎的 Search 與 Fetch API 開放給所有開發者，每 1,000 次成功呼叫各收 0.75 美元<Cite k="ds-changelog" /><Cite k="ds-pricing" />。

**混合推理與工具整合。** 自 V3.1 起，同一個模型可切換思考與非思考模式；V4 系列提供 low、high、max 三段思考強度，API 同時相容 OpenAI 與 Anthropic 格式並原生支援 Responses API，可直接接上 Claude Code、Codex、OpenCode 等程式 <Term id="agent">Agent</Term> 工具<Cite k="ds-changelog" />。1017 版另針對 DeepSeek Harness、騰訊 CodeBuddy 與 WorkBuddy 等平台最佳化，官方稱它在提升評測成績的同時，也縮短了任務執行時間與輸出長度<Cite k="ds-v41-1017-news" />。

**MoE 換取速度，但輸出偏長。** 整個系列都採 <Term id="moe">MoE</Term> 架構，<Term id="active-parameters">啟用參數</Term>遠小於總參數。Artificial Analysis（AA）在 2026-11-13 顯示的 DeepSeek 官方 API 輸出速度，V4.1-Flash-1017 約每秒 156 tokens，V4-Pro（0813）約每秒 77 tokens，前者約為後者的兩倍；這類速度會隨服務負載變動，只宜當作相對參考<Cite k="aa-ds-v41-flash-1017" /><Cite k="aa-ds-v4-pro" />。不過輸出快不等於任務快：AA 指出 1017 版相當冗長，跑完整套 v5 指數共產生約 1.74 億個輸出 tokens，高於同級開放權重模型的中位數（約 1.06 億）；每項任務平均約 14.8 分鐘，也略高於同級模型中位數的 14.6 分鐘<Cite k="aa-ds-v41-flash-1017" />。

## 適合與不適合的用途

適合：

- **大量、可延後的批次工作**：文件摘要、翻譯、資料標註等可排到離峰時段，成本再減半。
- **長文件與大型程式碼庫**：100 萬 tokens 上下文加上便宜的快取命中價，適合反覆讀取同一批資料的 Agent。
- **自架與微調**：MIT 授權沒有營收門檻或標示義務，比 <ModelChip id="moonshot-kimi" /> 與 <ModelChip id="minimax" /> 的自訂授權單純。
- **數學與競賽程式**：V4.1-Flash 9 月版官方公布的 Codeforces 評分為 3471<Cite k="hf-v41-flash" />；1017 版沒有另外公布這項成績。

不適合：

- **需要最強綜合能力的任務**：AA 綜合智慧指數 v5.0.1 中，V4.1-Flash-1017 為 33，雖然在 AA 標示為開放權重的模型中僅次於 Kimi K3.1 Pro（46），但與封閉旗艦 Claude Fable 5.2（65）、Gemini 4 Carbon（60）仍有明顯差距<Cite k="aa-leaderboard-v5" />。
- **不容許幻覺的事實問答**：AA 的知識可靠度測驗（Omniscience v1.1）中，1017 版答對率約 40%，答不出正確答案的題目約有 64% 仍給出錯誤答案，而不是表明不知道，宜搭配 <LearnLink id="rag-and-vector-search">RAG</LearnLink> 查證<Cite k="aa-ds-v41-flash-1017" />。
- **需要長期固定版本的系統**：同一個 API 名稱背後的模型常被直接替換。V4.1-Flash 9 月版上線約 5 週就由 1017 版接手；V4-Pro 也曾被宣告逐步淘汰，之後才改為延續服務<Cite k="ds-changelog" /><Cite k="ds-v41-news" />。自行部署時可固定使用 Hugging Face 上的特定版本權重。
- **資料治理要求嚴格的組織**：Anthropic 2026 年 9 月的報告指控 DeepSeek 等中國實驗室把使用者對話送進 Claude，再用回覆<Term id="distillation">蒸餾</Term>其能力。這是 Anthropic 的單方說法<Cite k="anthropic-sep-2026" />，採購前宜自行評估。

## 評測解讀
