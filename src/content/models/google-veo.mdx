## 系列概覽

Veo 是 <CompanyChip id="alphabet">Alphabet</CompanyChip> 旗下 Google DeepMind 的影片生成模型系列。2024 年 5 月首度亮相，同年 12 月推出 Veo 2；2025-05-20 的 Veo 3 首度在同一次生成中產出畫面與對白、音效、環境音，DeepMind 執行長 Demis Hassabis 形容這是 AI 影片告別「默片時代」<Cite k="wiki-veo" />。依模型卡，Veo 3 採用<Term id="diffusion-model">擴散模型</Term>中的潛在擴散技術，同時對音訊與時空影片的潛在表示去噪<Cite k="veo3-card" />。

2026 年起，系列重心轉向 Gemini Omni。2026-05-19 的 Google I/O 發表 Gemini Omni Flash，定位是「從任何輸入生成任何內容，從影片開始」：可同時接受文字、圖片、音訊與影片作為參考，並以對話方式逐步修改影片。Google 把它定位為繼圖像模型 Nano Banana 之後，把 Gemini 的理解與推理帶進影片生成與編輯的下一步<Cite k="omni-blog" />。Gemini API 文件目前把 Omni Flash 列為預設的影片生成模型，Veo 3.1 則保留給場景延伸、尾影格控制或既有工作流程<Cite k="video-docs" />。

## 特性分析

- **音畫同步**：Veo 3 之後的版本都能原生生成對白與音效；DeepMind 也在模型頁坦承，短句對白的自然度與同步仍在改進<Cite k="veo-page" />。
- **控制工具多**：Veo 3.1 支援最多 3 張參考圖、首尾影格、場景延伸，片長 4、6 或 8 秒，2026-01-13 起可輸出 4K<Cite k="gemini-changelog" />。
- **對話式編輯**：Omni Flash 是原生<Term id="multimodal">多模態</Term>的 Transformer 模型，能把 Gemini 的世界知識帶進影片，多輪替換物件、換場景或改鏡頭角度<Cite k="omni-card" />。GA 版 gemini-omni-1.1-flash 輸出 3–10 秒、24 fps，1080p 與 4K 以放大方式產生<Cite k="omni-model-page" />；新增的場景延伸每次 10 秒、累計最長 40 秒，並可用 360p 低成本預覽<Cite k="omni11-blog" />。
- **兩種計價**：Veo 依秒計價，Veo 3.1 標準版 720p／1080p 每秒 0.40 美元、Fast 版 720p 每秒 0.10 美元、Lite 版 720p 每秒 0.05 美元；Omni Flash 改以 <Term id="token">Token</Term> 計價，輸入每百萬 tokens 1.50 美元、影片輸出 17.50 美元，以 720p 每秒 5,792 tokens 換算約每秒 0.10 美元<Cite k="gemini-pricing" />。
- **內容標記**：Omni 生成的影片都嵌入 SynthID 數位浮水印，可在 Gemini App 與 Google 搜尋中驗證<Cite k="omni-blog" />。

## 適合與不適合的用途

**適合**：社群短影音、廣告素材與分鏡預覽（previs）這類需要快速出片、反覆修改的工作；需要對白與音效同步的短片；已使用 Gemini App、Google Flow、YouTube Shorts 或 Gemini API 的團隊，可以直接整合。企業若需要資料落地、客戶自管金鑰等控管，可改走 Google Cloud 的 Gemini Enterprise Agent Platform：Veo 3.1 已在該平台 GA<Cite k="agent-platform-veo" />，Omni 1.1 Flash 也可透過該平台的 API 使用<Cite k="omni11-blog" />。

**不適合**：需要一鏡到底的長片——單段只有 3–10 秒，Omni 1.1 延伸後累計也只到 40 秒<Cite k="omni11-blog" />，更長的內容得靠剪接拼接；需要自行部署或微調的場景——全系列為封閉權重；對畫面文字或複雜動作要求極高的鏡頭，模型卡仍列為已知限制<Cite k="omni-card" />。Google 的模型汰換也很快：Gemini API 上的 Veo 2 與 Veo 3 已在 2026-06-30 停止服務，Veo 3.1 預覽版與 Omni Flash 預覽版都排定 2026-10-22 停止，整合時要預留遷移成本<Cite k="gemini-deprecations" />。

## 評測解讀

影片模型沒有像語言模型那樣有標準答案的題庫，主流做法是讓人類盲測兩兩比較，再換算成 <Term id="elo-rating">Elo 分數</Term>。截至 2026-10-06，Artificial Analysis 的文生影片榜（AA-Video-T2V v2.0，含音訊）上，Gemini Omni 1.1 Flash 為 1,113 分、排第 8，Veo 3.1 為 962 分、排第 18；前段班是阿里巴巴 <ModelChip id="alibaba-wan">Wan 3.0</ModelChip>（1,156 分）、以 MiniMax H3 為基礎的 Utopai X、字節跳動 <ModelChip id="bytedance-seedance">Seedance 2.5</ModelChip> 與 MiniMax H3<Cite k="aa-t2v" />。但在同日讀取的 Arena（lmarena.ai）文生影片榜上，Omni 1.1 Flash 以 1,516 分居首（前 4 名的信賴區間重疊），Veo 3.1 則在第 12 名附近<Cite k="arena-t2v" />。AA 的圖生影片榜（Omni Flash 預覽版）與影片編輯榜（Omni 1.1 Flash）上，Omni 都排第 3，但與相鄰名次的分數差距在誤差範圍內<Cite k="aa-i2v" /><Cite k="aa-edit" />。若把成本一起看，AA 以官方 API 生成 1 分鐘 1080p 影片估算，Omni 1.1 Flash 約 9.12 美元、Veo 3.1 標準版約 24 美元、Wan 3.0 約 12 美元：Omni 比 Veo 3.1 標準版分數更高、單價也更低，但 Veo 3.1 Fast（約 7.20 美元）與 Lite（約 4.80 美元）仍較便宜<Cite k="aa-t2v" />。

兩個榜單結論不同，原因包括：投票者不同（AA 為招募評審、Arena 為公開使用者）、題目組成與解析度設定不同，以及新模型票數較少——Omni 1.1 Flash 在 Arena 只有約 1,800 票，誤差 ±15 分。DeepMind 模型頁引用的 MovieGenBench 人評結果屬於原廠評測，比較對象與設定由原廠選定，宜視為參考<Cite k="veo-page" />。影片榜單幾乎每月都有新模型加入，引用排名時務必註明日期。
