summary: "Google DeepMind 的影片生成模型家族。Veo 系列（Veo 2、Veo 3、Veo 3.1）生成數秒長的短片，Veo 3 起以潛在擴散技術同時生成畫面與原生音訊；2026-05-19 發表的 Gemini Omni Flash 把 Gemini 的多模態理解與影片生成結合，能以對話逐步編輯影片。2026-11-05 推出的 Gemini Omni 1.2 Flash 單段最長 15 秒、影片輸出價降約 30%，Gemini API 文件改為指定以它生成與編輯影片；Veo 3.1 在 Gemini API 的預覽版已於 2026-10-22 停止，改由 Google Cloud 企業平台提供。"
strengths:
  - "畫面與對白、音效、環境音一次生成：Veo 3（2025-05）起支援原生音訊，Omni Flash 延續此能力。"
  - "Omni Flash 可多輪對話編輯影片（換物件、換場景、改鏡頭角度）；Omni 1.2 Flash 在 Artificial Analysis 影片編輯榜排第 2，在 Arena 文生影片榜（2026-11-08）暫列第 1。"
  - "控制工具齊全：Omni 1.2 Flash 單段 3–15 秒，支援首尾影格插補、最多 6 張參考圖維持角色一致、延伸到最長 30 秒，以及 360p 至 4K 解析度。"
  - "價格下修：Omni 1.2 Flash 影片輸出每百萬 tokens 12 美元，720p 約每秒 0.07 美元、360p 預覽約每秒 0.023 美元；AA 估算 1 分鐘 1080p 約 6.26 美元，低於 Omni 1.1 Flash 的 9.12 美元。"
  - "與 Gemini App、Google Flow、YouTube Shorts、Gemini API 與 Google Cloud 企業平台整合，輸出均嵌入 SynthID 浮水印。"
weaknesses:
  - "單段影片短：Omni 1.2 Flash 為 3–15 秒，延伸後累計也只到 30 秒，更長的內容仍需剪接。"
  - "名次因榜而異：AA 文生影片榜 v2.1（含音訊，2026-11-13）上 Omni 1.2 Flash 排第 5，落後 Wan 3.0、Utopai X、MiniMax H3 與 Seedance 2.5；圖生影片榜只排第 14，Veo 3.1 則落到文生影片榜第 25。"
  - "版本汰換快：Gemini API 上的 Veo 2、Veo 3 已於 2026-06-30 停止，Veo 3.1 與 Omni Flash 預覽版於 2026-10-22 停止，GA 才約三個月的 Omni 1.1 Flash 也將在 2026-12-03 自動轉到 1.2，整合者需頻繁遷移。"
  - "封閉權重、無法自行部署或微調；1080p 與 4K 以放大方式產生，API 尚不支援上傳音訊作為輸入，上傳影片的編輯與延伸在歐洲經濟區、瑞士與英國暫不提供。"
bestFor:

  - "分鏡、前期視覺化（previs）與概念片"
  - "需要對白與音效同步的短片"
  - "已使用 Gemini API 或 Google Cloud 的企業影片生成管線"

## 系列概覽

Veo 是 <CompanyChip id="alphabet">Alphabet</CompanyChip> 旗下 Google DeepMind 的影片生成模型系列。2024 年 5 月首度亮相，同年 12 月推出 Veo 2；2025-05-20 的 Veo 3 首度在同一次生成中產出畫面與對白、音效、環境音，DeepMind 執行長 Demis Hassabis 形容這是 AI 影片告別「默片時代」<Cite k="wiki-veo" />。依模型卡，Veo 3 採用<Term id="diffusion-model">擴散模型</Term>中的潛在擴散技術，同時對音訊與時空影片的潛在表示去噪<Cite k="veo3-card" />。

2026 年起，系列重心轉向 Gemini Omni。2026-05-19 的 Google I/O 發表 Gemini Omni Flash，定位是「從任何輸入生成任何內容，從影片開始」：可同時接受多種素材作為參考，並以對話方式逐步修改影片。Google 把它定位為繼圖像模型 Nano Banana 之後，把 Gemini 的理解與推理帶進影片生成與編輯的下一步<Cite k="omni-blog" />。2026-08-27 的 Omni 1.1 Flash 在 Gemini API 正式上線；2026-11-05 再推出 Omni 1.2 Flash，單段延長到 15 秒、影片輸出價降約 30%，付費層速率上限加倍<Cite k="gemini-changelog" />。Gemini API 的影片生成文件現在指定以 Omni 1.2 Flash 生成與編輯影片，並註明 Veo 3.1 在 Gemini API 的預覽版已於 2026-10-22 停止，需要 Veo 3.1 的使用者改走 Google Cloud 的企業平台<Cite k="video-docs" />。

## 特性分析

- **音畫同步**：Veo 3 之後的版本都能原生生成對白與音效；DeepMind 也在模型頁坦承，短句對白的自然度與同步仍在改進<Cite k="veo-page" />。
- **對話式編輯**：Omni Flash 是原生<Term id="multimodal">多模態</Term>的 Transformer 模型，能把 Gemini 的世界知識帶進影片，多輪替換物件、換場景或改鏡頭角度<Cite k="omni-card" />。
- **1.2 版的規格**：單段 3–15 秒，可選 360p、720p、1080p 與 4K，其中 1080p 與 4K 以放大方式產生；首尾影格插補 3–10 秒；最多 6 張參考圖維持角色與物件一致；延伸時以影片最後 10 秒為依據，每次 3–10 秒、累計最長 30 秒<Cite k="omni-guide" />。模型頁另標示輸出 24 fps、輸入上限 131,072 tokens、輸出上限 65,536 tokens<Cite k="omni-model-page" />。
- **計價方式**：Omni 以 <Term id="token">Token</Term> 計價。1.2 Flash 輸入每百萬 tokens 1.50 美元、影片輸出 12 美元；官方以 720p 每秒 5,792 個輸出 tokens 換算，約每秒 0.07 美元，10 秒短片約 0.70 美元，360p 預覽約每秒 0.023 美元。1.1 Flash 的影片輸出仍是 17.50 美元，但 2026-12-03 起請求會自動轉到 1.2 並改用 1.2 的價格<Cite k="gemini-pricing" />。
- **已知限制**：API 目前不支援上傳音訊作為輸入或參考；只能在影片尾端延伸；上傳影片的編輯與延伸在歐洲經濟區、瑞士與英國暫不提供<Cite k="omni-guide" />。
- **內容標記**：Omni 生成的影片都嵌入 SynthID 數位浮水印，可用程式偵測來源<Cite k="omni-guide" />。

## 適合與不適合的用途

**適合**：社群短影音、廣告素材與分鏡預覽（previs）這類需要快速出片、反覆修改的工作；需要對白與音效同步的短片；已使用 Gemini App、Google Flow、YouTube Shorts 或 Gemini API 的團隊，可以直接整合。企業若需要資料落地、客戶自管金鑰等控管，可改走 Google Cloud 的 Gemini Enterprise Agent Platform：Omni 1.2 Flash 在 2026-11-05 同步於該平台 GA<Cite k="agent-platform-omni12" />，Veo 3.1 與 3.1 Fast 也仍在該平台 GA，支援終止日標示為 2027-05-04 或之後<Cite k="agent-platform-veo" />。

**不適合**：需要一鏡到底的長片——單段最長 15 秒，延伸後累計也只到 30 秒<Cite k="omni-guide" />，更長的內容得靠剪接拼接；需要自行部署或微調的場景——全系列為封閉權重；對畫面文字或複雜動作要求極高的鏡頭，模型卡仍列為已知限制<Cite k="omni-card" />。Google 的模型汰換也很快：Gemini API 上的 Veo 2 與 Veo 3 在 2026-06-30 停止，Veo 3.1 各預覽版與 Omni Flash 預覽版在 2026-10-22 停止，Omni 1.1 Flash 在 GA 約三個月後就排定 2026-12-03 轉到 1.2<Cite k="gemini-deprecations" />。雖然自動轉送不必改程式，但輸出長度與畫面風格可能改變，整合時要預留重新測試的成本。

## 評測解讀

影片模型沒有像語言模型那樣有標準答案的題庫，主流做法是讓人類盲測兩兩比較，再換算成 <Term id="elo-rating">Elo 分數</Term>。Artificial Analysis（AA）的文生影片榜在 2026 年 10 月由 v2.0 改為 v2.1，圖生影片榜也由 v1.0 改版為 v2.1，分數與名次會隨新投票與新模型變動，不宜與舊版逐分比較；AA 在 2026-10-27 改版為 v5 的綜合智慧指數則只用於語言模型，與影片榜無關。

截至 2026-11-13，AA 文生影片榜（AA-Video-T2V v2.1，含音訊，34 個模型）上，Omni 1.2 Flash 以 1,152 分排第 5，前面是阿里巴巴 <ModelChip id="alibaba-wan">Wan 3.0</ModelChip>（1,175 分）、以 <ModelChip id="minimax">MiniMax</ModelChip> H3 為基礎的 Utopai X、MiniMax H3 與字節跳動 Seedance 2.5；第 3 到第 8 名只差 11 分（1,161 至 1,150），彼此的信賴區間（約 ±13–15 分）重疊；Omni 1.1 Flash 為 1,127 分、第 13 名，Veo 3.1 為 963 分、第 25 名<Cite k="aa-t2v" />。各榜的名次差異不小：Omni 1.2 Flash 在影片編輯榜以 1,164 分排第 2<Cite k="aa-edit" />，在圖生影片榜卻只有 1,085 分、第 14 名<Cite k="aa-i2v" />。

Arena（lmarena.ai）的結論又不同。2026-11-08 的文生影片榜上，Omni 1.2 Flash 以 1,540 分居首，1.1 Flash 與標為 gemini-omni-flash 的初版分居第 2、3 名，Veo 3.1（含音訊）在第 14 名附近<Cite k="arena-t2v" />；圖生影片榜也是 Omni 1.2 Flash 第一（1,503 分）<Cite k="arena-i2v" />。但 1.2 Flash 在兩榜都標示 Preliminary，文生影片榜只有約 1,700 票、誤差 ±16 分。兩邊差異來自投票者（AA 為招募評審、Arena 為公開使用者）、題目組成與解析度設定，以及新模型票數較少。

成本也要一起看：AA 以官方 API 生成 1 分鐘 1080p 影片估算，Omni 1.2 Flash 約 6.26 美元，低於 1.1 Flash 的 9.12 美元、Veo 3.1 標準版的 24 美元與 Wan 3.0 的 12 美元，也低於 Veo 3.1 Fast 的 7.20 美元<Cite k="aa-t2v" />。DeepMind 模型頁引用的 MovieGenBench 人評結果屬於原廠評測，比較對象與設定由原廠選定，宜視為參考<Cite k="veo-page" />。影片榜單幾乎每月都有新模型加入，引用排名時務必註明榜單版本與日期。
