## 系列概覽

<CompanyChip id="world-labs">World Labs</CompanyChip> 由 AI 研究者李飛飛共同創辦並擔任執行長，以「空間智慧」為核心，開發能生成、重建與模擬 3D 世界的<Term id="world-model">世界模型</Term>。旗下有三條線：已商用的 Marble、研究預覽的即時畫面模型 RTFM，以及 2026-09-01 發表的新一代全模態模型 Atlas<Cite k="wl-atlas" />。Atlas 在 2026-11-12 正式開放，World Labs 官網與產品介紹也改以 Atlas 為主角<Cite k="wl-atlas-release" />。

2026-02 公司宣布募得 10 億美元，投資人包括超微、Autodesk、輝達等<Cite k="wl-funding" />。2026-09-28，<CompanyChip id="amd">超微（AMD）</CompanyChip>宣布以約 82 億美元全股票收購 World Labs，預計 2026 年底前完成，李飛飛將出任超微執行副總裁兼首席科學家<Cite k="amd-pr" />。World Labs 表示雙方去年起已在超微 GPU 上合作訓練與推論最佳化<Cite k="wl-amd" />。截至 2026-11-03 超微發布第三季財報時，這筆交易仍是擬議中的收購<Cite k="amd-q3" />。

## 特性分析

- **產出可帶走的 3D 世界**：與 Google <ModelChip id="google-genie">Genie</ModelChip> 這類逐格即時生成畫面的模型不同，Marble 產出的是持久存在、可自由走動的 3D 場景，並能匯出為高斯潑濺（以大量半透明色點描述場景的 3D 表示法）、網格或影片<Cite k="wl-marble" />。World API 把這些能力開放給開發者，生成約需 5 分鐘，輸出含 SPZ 高斯潑濺與 GLB 網格<Cite k="wl-api-docs" />。
- **Atlas 的整合嘗試**：同一個模型同時處理影像、相機位置與深度圖，能依指定相機路徑生成最長 1 分鐘的 1440p 影片、從一張到數十張照片重建場景，並為機器人產生模擬感測畫面<Cite k="wl-atlas" />。2026-11-12 起，Viewfinder 可從照片或生成圖片重建場景並渲染鏡頭路徑，Chisel 用粗略方塊配置引導場景結構，Splats to Mesh 把高斯潑濺轉成網格，Relight 則調整光線<Cite k="wl-atlas-release" />。
- **開發者工具鏈**：Atlas 開發者 API 把相機估計、新視角生成、局部修補、潑濺重建與網格轉換拆成一組任務，另提供 CLI、可讓 Claude 等用戶端直接呼叫的 <Term id="mcp">MCP</Term> 伺服器，以及 Blender 整合；文件也提醒開發者改用 Atlas 端點，把 Marble 與 World API 稱為舊版（legacy）<Cite k="wl-atlas-docs" />。
- **即時路線：RTFM 到 Frameboy**：RTFM 以自回歸<Term id="diffusion-model">擴散模型</Term>逐格生成畫面，把看過的畫面存成 <Term id="kv-cache">KV cache</Term> 作為世界記憶，目標是在單張 H100 上維持互動幀率<Cite k="wl-rtfm" />。2026-11-05 推出的 Frameboy 改用更大、訓練資料多出好幾個數量級的 Atlas，以最高每秒 15 格從雲端串流到瀏覽器；它不只能在既有視角之間補畫面，還能從單張圖片延伸出整個場景<Cite k="wl-frameboy" />。

## 適合與不適合的用途

**適合**：遊戲與影視特效的場景原型與鏡位規劃；建築與室內設計的空間視覺化，Atlas 可從照片或灰盒（graybox）配置建出空間，再匯出網格<Cite k="wl-atlas-release" />；為機器人訓練快速建立大量多樣的模擬環境，官方指出 Marble 生成的世界可整合進 NVIDIA Isaac Sim、MuJoCo 等模擬器<Cite k="wl-api" />，這類 <Term id="sim-to-real">sim-to-real</Term> 用途是世界模型連結實體 AI 的關鍵。World API 推出時，影視前製平台 Preview 已用它把單張圖片變成可自由取景的 3D 場景，建築設計平台 Fenestra 則把草圖與照片轉成可走動的空間<Cite k="wl-api" />。

**不適合**：需要物體運動、碰撞等物理模擬的工作（Marble 生成的是靜態 3D 場景資產）；需要低成本即時互動的體驗——Marble 每次生成約 5 分鐘，Frameboy 雖然即時，但必須在雲端高階 GPU 上執行，官方也承認成本比本機渲染高<Cite k="wl-frameboy" />；需要精確測量的工程應用，生成結果會「想像」補齊沒拍到的區域。需要穩定產能規劃的服務也要留意：Atlas 文件中的速率限制仍是「待公布」的暫定值<Cite k="wl-atlas-rate" />。

## 評測解讀

3D 世界生成還沒有像語言模型或影片模型那樣被廣泛採用的人類偏好排行榜，本站的評測登錄表也沒有適用指標；Artificial Analysis 的綜合智慧指數在 2026-10-27 改版為 v5（與 v4 分數不能互比），但只評語言模型，同樣不適用。因此能引用的數字主要來自原廠。Atlas 發表文提供兩組比較：在相機控制生成上，評審判斷 Atlas 比 MiniMax H3、Gemini Omni Flash、Seedance 2.5 等影片模型更能依照指定鏡頭移動，選擇 Atlas 的比例為 75%–94%（依對手不同）；在稀疏視角 3D 重建上，7 個資料集的平均相對誤差（AbsRel，以千分之一為單位）為 25.3，低於第二名專門重建模型 Pi3X 的 28.7<Cite k="wl-atlas" />。

解讀時要注意：相機控制比較中，Atlas 直接接收相機參數，其他影片模型只能用文字描述鏡頭，這是對 Atlas 有利的設定；重建比較的基準模型由 World Labs 以統一流程自行重跑，分數未經獨立驗證。這些評測都在 2026-09-01 發表，當時 Atlas 尚未公開；2026-11-12 開放後，外界已能自行試用，但截至 2026-11-13 仍未見獨立的標準化評測。World Labs 也表示 Atlas 的表現隨訓練算力增加而提升，並預期這個趨勢會延續<Cite k="wl-atlas" />；這是原廠對規模化的判斷。對讀者而言，目前比較可靠的參考是實際試用 Marble 1.1 或 Atlas 的成品品質與匯出格式，是否符合自己的工作流程。
