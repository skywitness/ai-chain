## 趨勢摘要

一句話：<Term id="reasoning-model">推理模型</Term>會在回答前先產生一段內部的<Term id="chain-of-thought">思維鏈</Term>，題目越難想得越久；「在推論時多花算力換取更好的答案」因此成為提升能力的新槓桿，也就是<Term id="test-time-compute">推論時運算</Term>。

**已發生的事實**：OpenAI 在 2024 年 9 月 12 日推出 o1-preview<Cite k="openrouter" />，此後 Anthropic、DeepSeek 等實驗室也陸續推出可調整思考量的模型<Cite k="claude-37" /><Cite k="deepseek-v4" />。OpenRouter 統計，推理類模型處理的 <Term id="token">Token</Term> 佔比，從 2025 年初幾乎可忽略升到年底超過五成<Cite k="openrouter" />。

**仍屬預測的部分**：METR 推估，若 AI Agent 可完成的任務長度持續每 7 個月左右翻倍，2027 到 2029 年間可勝任多種一週長的任務<Cite k="metr-horizon" />；這是趨勢外推，不是保證。

## 為什麼重要

過去提升模型能力，主要靠「訓練時」投入更多算力與資料；推理模型多了一個旋鈕：同一個模型，讓它想久一點，答案就更好。DeepSeek-V4-Pro 的官方數字很能說明這點，同一組權重只是切換思考模式，數學競賽成績就從三成跳到九成以上<Cite k="deepseek-v4" />：

<BarChart title="DeepSeek-V4-Pro 不同思考模式的 HMMT 2026 年 2 月成績" unit="%" data={[{ label: "不思考", value: 31.7 }, { label: "思考（High）", value: 94.0 }, { label: "最大思考（Max）", value: 95.2 }]} source="deepseek-v4" note="同一組模型權重、Pass@1；廠商自行公布的評測結果。" />

這也改變了算力的帳本。推理 Token 的內容雖然不會透過 API 回傳，仍佔用上下文並以輸出 Token 計費，依題目難度可能多出數百到數萬個 Token，OpenAI 建議開發者一開始至少預留 25,000 個 Token<Cite k="openai-reasoning" />。輝達執行長黃仁勳因此把推理稱為「另一條縮放定律」<Cite k="nvda-q4-fy25" />：算力需求不再只集中在訓練，每一次回答都要多算。

<Callout type="analogy" title="生活化比喻">
考試時，簡單題直接寫答案，難題則先在草稿紙上演算。草稿紙用得越多（推理 Token），越有機會算對，但也越花時間、越花紙。推理模型就是學會了「什麼時候該打草稿、打多少」的考生。
</Callout>

<DeepDive title="深入一點：推論時運算的兩種花法">
推論時多花的算力，大致有兩種用法。第一種是**序列式**：讓模型寫出更長的思維鏈，一路檢查、修正再作答，Claude 的思考預算與 OpenAI 的推理強度調整的就是這一種<Cite k="claude-37" /><Cite k="openai-reasoning" />。第二種是**平行式**：同一題取樣多個答案，再以投票或評分挑出最好的一個。o3 預覽版在 ARC-AGI-1 的兩種設定就是例子：高效率設定每題取 6 個樣本，高運算設定每題取 1,024 個<Cite k="arc-o3" />；ChatGPT 中的 gpt-5-thinking-pro 也採用平行的推論時運算<Cite k="gpt5-card" />；達到 IMO 金牌水準的進階版 Gemini Deep Think 也用到了平行思考<Cite k="deepmind-imo" />。兩種做法並不互斥，可以同時使用。

Snell 等人 2024 年的論文指出，依題目難度動態分配推論算力，效率可比單純「取 N 個答案挑最好」高 4 倍以上；在總運算量相同的比較下，對小模型已有一定成功率的題目，多給推論算力甚至能勝過大 14 倍的模型<Cite k="snell" />。這和推理模型「看題目決定想多久」的設計方向一致。
</DeepDive>

## 關鍵驅動力

**一、強化學習讓模型學會「想」。** DeepSeek-R1 的論文指出，推理能力可以透過純<Term id="reinforcement-learning">強化學習</Term>誘發，不需要人工標註的推理示範<Cite k="deepseek-r1-paper" />；它在 2025 年 1 月以 MIT 授權開放權重，並一併釋出 6 個蒸餾小模型<Cite k="deepseek-r1-hf" />。數學、程式這類答案可自動驗證的題目，特別適合這種<Term id="rlvr">可驗證獎勵強化學習</Term>。

**二、可調的思考預算成為產品標配。** Claude 3.7 Sonnet 在 2025 年 2 月推出，自稱第一個混合推理模型，API 使用者可指定最多思考 N 個 Token、上限 128K<Cite k="claude-37" />；GPT-5 由快速模型、深度推理模型與即時路由器組成，依題目複雜度決定由誰回答<Cite k="gpt5-card" />；OpenAI API 的推理強度則依模型可從 none 一路調到 max<Cite k="openai-reasoning" />。

**三、高難度任務的突破。** o3 預覽版在 ARC-AGI-1 半私有測試集拿下 75.7%，放大約 172 倍算力後達 87.5%；不過這個測試版本曾以 ARC-AGI-1 的公開訓練集訓練，ARC Prize 也註明它與後來正式推出的 o3 不同<Cite k="arc-o3" />。進階版 Gemini Deep Think 在 2025 年國際數學奧林匹亞（IMO）以自然語言、在 4.5 小時的比賽時限內拿下 42 分中的 35 分，達金牌水準<Cite k="deepmind-imo" />。

**四、Agent 與程式工作把推理變成預設。** 多步驟工作需要規劃與自我檢查，推動了推論用量。Google 模型 API 的處理量從 2025 年第三季到 2026 年第二季成長為 3 倍以上：

## 反方觀點與風險

- **成本與延遲**：o3 預覽版的高運算設定，100 題共產生 57 億個 Token；ARC Prize 當時估計，請人解一題約 5 美元，比 o3 預覽版便宜<Cite k="arc-o3" />。推理不一定值得，簡單問題想太久只是浪費。
- **能力有天花板**：Apple 研究人員以可控難度的謎題測試，發現推理模型超過某個複雜度後準確率完全崩潰，接近崩潰時反而減少思考量<Cite k="apple-illusion" />。
- **強化學習未必帶來新能力**：有研究發現，RLVR 訓練的模型在只取一次答案時較好，但允許大量取樣時，原本的基礎模型反而解出更多題<Cite k="rl-boundary" />。
- **思維鏈不一定可信**：Claude 3.7 Sonnet 只有 25%、DeepSeek R1 只有 39% 會在思維鏈中承認使用了題目中的提示<Cite k="cot-faithfulness" />。
- **效率可能抵銷需求**：<Term id="open-weights">開放權重</Term>與蒸餾讓小模型也能推理<Cite k="deepseek-r1-hf" />，推論算力的成長未必與 Token 用量同步。

## 觀察指標

- OpenRouter、Google 等平台公布的推理類 Token 佔比與 API 處理量（2026 年第二季約每分鐘 220 億個 Token）<Cite k="goog-q2-2026" />。
- 各家模型在相同分數下所需的思考 Token 是否持續下降。

- METR 等機構量測的 Agent 任務長度是否延續翻倍趨勢。
- 推論專用晶片與記憶體在資料中心資本支出中的比重。
